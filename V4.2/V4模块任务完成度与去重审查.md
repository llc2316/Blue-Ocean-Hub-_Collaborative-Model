# V4模块任务完成度与去重审查

> 审查日期：2026-07-25  
> 活动基线：`V4整合/`  
> 运行模式：`interface_smoke`，24 h、1 h步长  
> 数据来源类型：模型仿真结果；全部工程规模、初态及未签认参数仍为
> **[假设值，待企业调研校准]**

## 1. 审查结论

V4已经完成“源侧边界—跨模块请求—专业模块响应—产品交付—实际总账—多目标评价”的
接口闭环，但“接口闭环”不等于各专业能力均已达到工程完整程度。

- 4.3已完成风电、光伏、潮流能设备模型与85%/10%/5%装机组合的源侧聚合；
- 4.4已完成唯一公共母线实际功率总账，但不负责跨模块调度；
- 4.5已完成电池能量状态、电解制氢和储氢库存响应，但尚未完成构网动态、季节尺度和期末状态约束；
- 4.6已完成任务、队列、SLA、PUE和算力收益映射，是算力产品的“生产模块”；
- 4.7已完成电力、氢气、算力服务和海洋用能的交付边界，是产品“通道与结算量模块”；
- 4.9才是当前唯一跨模块功率分配入口，现阶段属于确定性可行性规则，不是最优调度器；
- 4.8只评价已提交实际量，不参与物理调度。

因此，项目文案不应表述为“4.4进行功率统筹调度”，而应表述为：
**4.9统筹分配，4.3—4.7执行专业响应，4.4进行实际功率平衡核账。**

## 3. 分模块任务完成度

### 3.1 4.3多元供能

**已完成**

- 漂浮式风电、漂浮式光伏、潮流能设备出力模型；
- 5 min/W到1 h/MW的能量守恒聚合；
- 逐源可用功率、实际功率、辅机和集电损耗明细；
- 85%/10%/5%装机组合及互补性、情景覆盖检查。

**未完成或仅为代理**

- 当前联调资源序列为合成基线，不是签认海域实测年序列；
- 未完成8760 h、极端天气、故障和相关性场景；
- 波浪能仅预留，未进入当前供能组合；
- 装机占比是容量占比，不等于能量占比或经济最优占比。

结论：4.3已完成供能子模型和接口任务，尚未完成工程资源评估与容量优化。

### 3.2 4.5短时储能与长时氢储

**已完成**

- 电池充放电功率、效率、SOC和能量边界；
- 电解槽最低/额定功率、SEC、产氢量、水耗和启动事件；
- 储氢损失、可交付库存、4.7提氢后状态提交；
- 与4.4、4.7、4.8、4.9的接口闭合。

**未完成**

- “短时储能”目前是1 h能量调度模型，未模拟秒级—分钟级构网、调频、调压和黑启动；
- “长时储能”目前只运行24 h，未证明跨周、季节转移能力；
- 配置声明的电池循环/最低期末规则及储氢期末规则未进入4.9硬约束；
- 当前结果消耗初始电池能量和初始氢库存，不能直接用于不同通道经济性比较。

结论：4.5完成了能量层响应原型，但未完成构网动态和长周期库存约束。

### 3.3 4.6绿色算力

**已完成**

- 刚性、柔性、可选任务与队列/SLA模型；
- IT功率、辅助功率、设施功率和PUE映射；
- 任务服务量、延期、丢弃、收入、SLA罚金和变动运维输出；
- 接收4.9逐时功率上限并返回实际功率；
- 4.8采用4.6任务级收入，内部电费不重复计入项目成本。

**需修正**

- 4.6边界预发布的条件在线最低功率为10 MW，而当前任务模型响应给出的在线底座约为
  2.394 MW；当前约7.618 MW设施功率是任务服务结果。应由4.6在调度前发布与内部模型
  一致的动态边界；
- MWh-CS由等效GPU功率归一化，仍为 **[假设值，待企业调研校准]**；
- 当前任务、价格和海温仍含代理或回退数据。

结论：4.6已经具备高价值柔性消纳模型，但动态可行域回传仍需完善。

### 3.4 4.7多形态输出

**V4正式入口已完成**

- 电力：海缆送端功率、受端电量、容量和损耗；
- 氢气：接收4.5可交付库存，执行管道/船运能力与交付损耗；
- 算力：接收4.6已完成服务量，执行光缆服务能力裁剪并形成交付量；
- 海洋用能：完整需求、刚性/柔性服务、未供量和违约状态。

**限制**

- 未做海缆潮流、动态损耗、通信路由和船舶逐航次优化；
- 当前氢交付采用管道优先、船运补充的汇总模型，未形成船运独立端口、船期和物流成本；
- 当前电力外送为0、氢气来自初始库存，尚未形成四类产品同时输出的联合示范场景；
- 4.7只负责交付，不应再次计算PUE、制氢库存、全系统平衡或总目标。

结论：4.7完成了产品交付边界，但当前24小时结果没有覆盖全部输出通道。

### 3.5 4.4公共母线

4.4按各模块`actual`量核算：

```text
源侧实际功率 + 电池放电 + 电网输入
= 电池充电 + 电解槽 + 数据中心 + 海缆外送 + 海洋用能
 + 源侧辅机 + 公共损耗 + 弃电
```

该式是冻结接口中的实际功率守恒核算式。4.4不决定负荷优先级、不生成设备请求，
缺供也不作为虚拟电源进入等式。

结论：4.4已完成唯一物理总账任务，但不是统筹调度器。

## 5. 需要优先补齐的模型能力

1. 由4.6模型在4.9调度前发布逐时在线最低功率、最大功率和队列边际需求；
2. 在4.9加入电池期末SOC和储氢期末库存约束，明确初始库存成本或机会价值；
3. 将4.6响应释放的剩余功率继续分配到海缆、制氢或储能，所有通道耗尽后才能记弃电；
4. 建立氢气管输/船运独立端口、船期、能耗和成本；
5. 建立至少72 h全通道验收场景，确保电力、当期制氢、算力和海洋用能均出现非零输出；
6. 扩展至8760 h，区分电池短时能量调节与氢储跨日/季节转移；
7. 将4.9可行性规则升级为带期末状态、启停和多产品价值的正式优化模型；
8. 在上述约束完成前，不用当前净收益证明“多形态输出优于单一外送”。
