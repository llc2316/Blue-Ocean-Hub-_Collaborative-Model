# 4.6 绿色算力负荷

V4 联合运行默认采用 `DC_model_v2_1` 的 SLA 弹性任务模型。功率跟随模型仅作为“无限任务池”的富余电力吸纳上界，不作为刚性任务或可靠性模型。

4.6负责算力服务的生产：PUE、IT/辅助功率、任务队列、SLA和任务级收益均在本模块计算。
4.7只接收4.6已经完成的服务量，施加光缆交付能力并形成最终交付量，不得重新计算PUE、
任务服务或算力收入。

- `DC_model_v2_1/`：SLA 主模型、功率跟随对照模型、配置、测试及运行数据。
- `integration/`：发布 4.6 边界，接收 4.9 请求，并返回功率、任务服务、队列和 SLA 字段。
- `docs/4.6绿色算力负荷模型与V4集成说明.md`：模型选择、字段语义及请求—响应—再调度规则。
- `docs/4.6公开数据替代与市场校准清单.md`：公开数据替换、GitHub数据集适用性、剩余假设及算力成本收益口径。

已删除当前模型明确不读取的`trace_seren.csv`、`EQCAM_Dataset.csv`和根级`data_stream` NetCDF。当前运行仍保留任务聚合表、设备参数、冷却参数、价格接口及实际使用的CMEMS海温文件。
