# 4.5 电解制氢系统集成模型 (空罐验证版)

本节整合电解槽设备模型(第3节)与系统耦合约束(第4.1-4.3节), 定义电解制氢系统的完整输入输出变量、核心调度约束与模型假设.

## 关键修改: 从空罐开始验证

针对初始库存零成本缺陷, 将初始条件从 H0=24t, E0=20MWh 改为 H0=0, E0=0:
- 储氢罐日初没有安全库存, 制氢必须实时满足交付
- BESS日初没有电量, 必须先充电再放电
- 期末约束保持 H_T>=0、E_T>=0
- 初始填充成本从投资中移除 (650.251 -> 650.000 百万元)

## 4.5.1 系统边界与接口定义
边界采用交流侧口径, 包含电解槽本体/整流/水处理/压缩纯化. SEC=56.77 kWh/kg. 接口: 电力(母线)、氢气(储氢)、经济(评价).

## 4.5.2 输入变量
四类: 电力(P_bus,t, p_t^e)、状态(a_t, H_t, E_t)、需求(D_H2,t, p_H2)、场景(设备参数, 项目边界).

## 4.5.3 输出变量 - 完整产氢链
12项: P_ely,t, u_t, DeltaP, m_H2,t, V_water, P_aux, FLEH_t, H_t/H_t+1, m_sale, m_short, m_vent, eta_load/SEC.

## 4.5.4 核心调度约束

### 4.5.4.1 功率调度边界
P_t^remaining < alpha_min*P_rated 则停机; 否则在 min(剩余, 额定, 储氢, 爬坡, 需求) 取可行值.
(20) P_ely,t^req = min(P_t^remaining, P_rated, P_t^tank, P_t^ramp, P_t^demand)
(21) s.t. P_ely,t >= alpha_min*P_rated or P_ely,t = 0

### 4.5.4.2 电池期末状态约束
(22) SOC_T >= SOC_0 or SOC_T = SOC_0  -- H0=0时等价于E_T>=0

### 4.5.4.3 储氢期末约束
(23) M_H2,T >= M_H2,0  -- H0=0时等价于H_T>=0

### 4.5.4.4 系统耦合约束
制氢/储氢/BESS通过母线平衡(式15)和储氢守恒(式9)耦合, 无预设优先级.

## 4.5.5 经济评价接口
需读取: 电解槽耗电、变动运维、水处理/压缩/纯化成本、储氢损耗、退化成本、年化CAPEX、库存价值.

A6-A10: 单槽聚合[待校]、固定SEC[需文献]、瞬时启停[需文献]、线性退化[需文献]、经济边界.
