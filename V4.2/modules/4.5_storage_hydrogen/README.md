# 4.5 电池—制氢—储氢

- `integration/`：电池SOC、电解槽SEC、启停事件、等效满负荷小时、产氢、水耗、储氢损失、可交付量和提氢后库存提交适配器。
- `docs/电能制氢建模.md`：当前可维护的建模正文；图片和可复算CSV使用相对路径保存在`docs/assets/`。
- `reference_model/blue_hub_demo_and_figures.m`：独立24小时方法算例及图表生成脚本，不进入V4联合调度。
- `reference_model/`中的DOCX和XLSX：方法算例快照，用于版式、公式和财务表追溯；它们不是当前`interface_smoke`联合结果。DOCX图片均为内嵌对象，不依赖外部路径。
- `docs/4.5公开数据替代与接口审查.md`：公开数据替代、仍待企业校准项以及4.4/4.8/4.9接口结论。

联合入口不调用原演示中的风电、外送、弃电或跨模块优化逻辑。

当前联合代码已经执行SOC和氢库存的逐时边界，但尚未把配置中的电池循环期末规则和
储氢期末规则作为4.9硬约束。`interface_smoke`结果消耗了部分初始电池能量和全部初始
储氢，因此只用于接口验证，不用于长期循环经济性结论。
