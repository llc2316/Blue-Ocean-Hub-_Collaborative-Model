# 4.8 全生命周期经济性参数、核算边界与重算结果

> 修订日期：2026-07-26  
> 角色口径：产业调研员＋优化建模师＋产业落地顾问  
> 适用范围：V4联调对比与第5章方案筛选，不构成投资决策、供应商报价或融资承诺。

## 1. 本次补全内容

4.8已由“短周期变动成本—收入账”扩展为以下两层：

1. **联调周期损益层**：计入折旧、融资成本、固定运维、替换准备金、变动成本、惩罚成本和产品收入；
2. **25年折现现金流层**：输出初始CAPEX、建设期融资、含融资CAPEX、替换成本现值、全寿命成本现值，以及含/不含惩罚成本的NPV。

初始CAPEX不会同时作为一次性支出和周期年化成本重复计入。联调周期中“折旧＋融资成本”
等于初始投资的资本回收额；全寿命NPV中则直接计入含建设期融资的CAPEX现值。

## 3. 计算方法

资本回收因子：

$$
\mathrm{CRF}=\frac{r(1+r)^n}{(1+r)^n-1}.
$$

来源类型：**美国国家实验室官方技术基准（NREL ATB Equations & Variables）**。
本情景采用25年、8%折现率；8%为现有项目情景值，**[假设值，待企业调研校准]**。
NREL公开融资方法用于证明应显式计入资本成本，但其美国税收和融资结构不直接移植到本项目。

建设期融资采用3年等额、年中支出代理：

$$
C_{\mathrm{IDC}}=
C_0\frac{1}{m}\sum_{j=1}^{m}
\left[(1+r)^{m-(j-0.5)}-1\right].
$$

该支出曲线尚未由EPC付款计划验证，属于 **[假设值，待企业调研校准]**，
公式应用边界 **[需查证文献支撑]**。

联调周期资本成本：

$$
C_{\mathrm{period,cap}}
=\left(C_{\mathrm{dep,annual}}+C_{\mathrm{finance,annual}}
+C_{\mathrm{replacement,annual}}+C_{\mathrm{FOM,annual}}\right)
\frac{H}{8760}.
$$

其中折旧按资产寿命直线法披露；融资成本为资本回收额扣除折旧后的部分；替换成本先按发生年份折现，再用CRF转为年替换准备金。税基尚未冻结，因此折旧不产生所得税抵扣，不能据此计算税后IRR。直线折旧和替换时点均为 **[假设值，待企业调研校准]**。

全寿命NPV采用：

$$
\mathrm{NPV}
=PV(R)-\left(C_{\mathrm{financed}}+PV(C_{\mathrm{replacement}})
+PV(C_{\mathrm{variable}})+PV(C_{\mathrm{FOM}})\right).
$$

24 h/48 h序列按$8760/H$重复为年度等效值。这仅是同口径方案比较假设，
不能代替8760 h或多年随机序列，状态标记为
`REPRESENTATIVE_PERIOD_REPEATED_ASSUMPTION`。

## 5. 重算结果

### 5.1 24 h接口联调情景

| 指标 | 重算值 |
|---|---:|
| 初始CAPEX | 86.868亿元 |
| 建设期融资 | 10.823亿元 |
| 含建设期融资CAPEX | 97.690亿元 |
| 年折旧 | 3.643亿元/年 |
| 年融资成本 | 5.508亿元/年 |
| 年固定运维 | 2.473亿元/年 |
| 替换成本现值 | 37.046亿元 |
| 年替换准备金 | 3.470亿元/年 |
| 24 h总成本/总收入/净成本 | 805.72/59.61/746.11万元 |
| 25年全寿命成本现值 | 313.931亿元 |
| 含惩罚NPV | -290.705亿元 |
| 不含惩罚NPV | -140.070亿元 |

结论：该情景只有40 MW电源，却配置700 MW海缆、100 MW电解槽和100 MW-IT算力，
资产利用率结构失配；同时算力SLA罚金为最大周期成本项。即使去除惩罚成本，NPV仍显著为负，
说明不是单纯调度罚金造成亏损。

### 5.2 48 h全通道行为情景

| 指标 | 重算值 |
|---|---:|
| 初始CAPEX | 256.388亿元 |
| 建设期融资 | 31.942亿元 |
| 含建设期融资CAPEX | 288.330亿元 |
| 年折旧 | 11.604亿元/年 |
| 年融资成本 | 15.407亿元/年 |
| 年固定运维 | 8.133亿元/年 |
| 替换成本现值 | 42.446亿元 |
| 年替换准备金 | 3.976亿元/年 |
| 48 h总成本/总收入/净成本 | 2263.74/417.43/1846.31万元 |
| 25年全寿命成本现值 | 441.011亿元 |
| 含惩罚NPV | -359.689亿元 |

结论：48 h场景成功激活电力、制氢、算力和海洋用能通道，但它是容量与调度行为压力测试，
不是可年化的典型资源年。该情景固定运维年值已经高于短序列年化收入，且源侧800 MW、
电缆/算力/制氢的容量配比未由规划优化确定，因此不能以此宣称项目无经济性，只能判定
当前配置和市场代理价下不能回收投资。

## 6. 成本主导项与下一步

24 h情景的CAPEX主导项依次为海底算力、电力海缆、PEM电解槽、漂浮式风电和储氢；
替换成本主要由算力IT更新驱动。后续第5章至少应：

1. 将四种输出方案分别重新定容，而不是共用一套满配资产；
2. 使用8760 h/多年资源序列计算利用小时、弃电、EENS和产品交付；
3. 对算力设备替换比例、海缆距离、融资率、承购价和SLA做敏感性；
4. 区分“行为验证场景”和“可年化经济场景”；
5. 获取EPC BOM、OEM运维合同、服务器更新周期、保险和退役报价后，替换全部假设值。

对应结果底稿为`v4_lifecycle_asset_ledger.csv`、`v4_lifecycle_summary.csv`、
`v4_economic_breakdown.csv`和`v4_kpi_summary.csv`。
