# 4.5 构网型短时储能—制氢—长时储氢

4.5已经形成“小时能量层＋秒级动态校核层＋连续长周期库存层”三个彼此分离、可独立验收的子模型。跨模块电力分配仍只由4.9决定，4.5只发布边界、执行物理响应并提交状态。

## 代码结构

- `model/v4_storage_hydrogen_core_4_5.m`：统一BESS能量、电解槽模块启停、固定SEC产氢、给水、储氢损失、同一时段流入/提取和终端状态检查。
- `model/v4_gfm_regfm_b1_dynamic_4_5.m`：基于NREL/WECC REGFM_B1的正序降阶构网动态代理，含P–f虚拟摆动、Q–V控制、正序电流限值和秒级SOC积分。
- `model/v4_seasonal_hydrogen_storage_4_5.m`：保持完整时序的长周期储氢递推，不允许24 h窗口重置。
- `integration/v4_storage_hydrogen_boundary_4_5.m`：向4.9发布显式期初状态、即时可充/可放边界、构网备用和黑启动可用标识。
- `integration/v4_storage_hydrogen_response.m`：联合模型响应入口，调用唯一物理核心，不再复制第二套SOC/库存方程。
- `integration/v4_finalize_4_5_packet.m`：提交4.5 RESPONSE包、质量守恒残差和终端约束状态。
- `run_4_5_standalone_validation.m`：运行72 h制氢、秒级构网/黑启动和8760 h季节库存三类场景。
- `tests/run_all_tests_4_5.m`：4.5独立验收入口。
- `docs/4.5多时标接口语义增补_V4.md`：在不改变4.2冻结公共端口的前提下，说明BOUNDARY、终端约束和构网备用诊断字段。

`reference_model/`中的MATLAB、DOCX和XLSX仍是早期24 h方法算例快照，不进入V4联合入口，也不代表当前联合仿真结果。

## 当前验收结果

2026-07-26实跑的21项独立断言全部通过：

- 72 h机制场景从0 kg开始制氢36,779.989 kg；
- 100 MW、1 h、SEC 56.77 kWh/kg对应1,761.493747 kg，公式与代码一致；
- 3 MW低于单模块最低负荷时停机，4 MW启动1套20 MW模块；
- 循环BESS期末偏差为0；不可行循环请求会返回硬错误；
- REGFM_B1负荷阶跃以15 MW基态运行并预留5 MW快速有功，频率最低点为49.7599 Hz，端口最大电流严格限制在1.0 pu，秒级有功积分对应BESS能量变化−0.114092 MWh；
- 120 s持续支撑场景实际调用2 MW/0.064444 MWh，频率最低点为49.9021 Hz，均未超过发布的5 MW/1 MWh备用；
- 超过正序电流边界的过载场景必须返回`feasible=false`，不能把限流后的降额供电误判为服务已满足；
- 黑启动代理在7.38 s建立端口电压/频率后，才于10 s分级带载；该结果仍只是正序降阶顺序检查；
- 连续8760 h机制场景峰值储氢2,123,344.962 kg，连续释放4,378 h，年末回到0；
- 同一场景使用现有72,000 kg罐时缺供2,051,344.962 kg，因此72 t只能代表日内—多日库存，不能称为季节储能；
- 12个连续730 h分块与一次8760 h计算的库存最大差为0，证明状态能够跨窗口传递。

上述季节功率序列、2.2×10⁶ kg机制储罐、REGFM控制参数、构网备用和黑启动SOC门槛均为 **[假设值，待企业/PCS/OEM调研校准]**。结果只证明数学机制和接口可行，不是推荐工程容量。

## 联合耦合状态

`run_v4_integration.m`先调用4.5 BOUNDARY，再让4.9读取显式状态和构网备用。BOUNDARY还发布电解槽期初启停状态、上一步功率和累计等效满负荷小时（FLEH），使滚动窗口不再重置启停与寿命状态。4.9已执行：

- 电池循环或最低期末能量硬约束；
- 储氢循环/最低期末库存硬约束；
- 构网备用功率、备用能量对小时级可调边界的收紧；
- 5×20 MW电解槽在“模块可独立启停”假设下的4 MW单模块最低功率；
- 4.9计划提氢、4.5逐时质量递推和4.7通道提取的一致性检查。

循环/最低期末目标只在窗口末点施加；窗口内SOC和储氢库存仅遵守物理下限与构网备用下限，因此不会把“期末目标”误当成逐时最低库存。算力实际用电低于计划时，释放功率可在同一小时直接转给电解槽并形成氢气直通交付，同时保持储氢库存和期末规则一致。

默认24 h `interface_smoke`仍从0 kg储氢开始，现已形成570.221 kg氢气、交付564.519 kg；电池期末能量严格回到20 MWh，期末储氢为0 kg。模块独立启停取决于共享BOP和OEM控制方案，当前必须保留 **[假设值，待OEM/BOP确认]** 标记。发布的5 MW/1 MWh构网备用同样是 **[假设值，待PCS厂商校准]**，不是厂商保证值。

REGFM_B1结果是正序降阶功能代理，不等于频率稳定性或黑启动工程认证。变压器涌流、谐波、三相不平衡、故障穿越、继电保护和多机并联仍需EMT、HIL及现场试验。
