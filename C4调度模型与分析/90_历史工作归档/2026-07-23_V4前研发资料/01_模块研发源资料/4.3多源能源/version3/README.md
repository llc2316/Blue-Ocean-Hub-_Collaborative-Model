# 4.3 多源能源供给模块 Version3

## 定位

Version3是4.3的独立开发与交付包，范围严格限定为：

```text
风电/漂浮式光伏/潮流能设备代理
  → 统一设备契约
  → 同测点多源聚合
  → 联合场景质量诊断
  → 多时间尺度互补指标
  → 仅风电/风光/风光潮等装机对照
```

4.3不计算母线最终平衡，不下达储能充放电指令，不包含SOC/SOH、构网控制、负荷价值分配、价格或收益。

## 相对公共基线V2的变化

1. 以公共基线中较完整的风电、光伏待机辅机逻辑作为统一版本；
2. 互补指标增加低出力事件次数、最大持续时间和缺口电量；
3. 增加联合场景相关性和时间持续性诊断；
4. 增加仅风电、风光、风光潮三组等总装机对照；
5. 增加独立自动化验收入口；
6. 明确Version3合成结果均为 `[假设值，待企业调研校准]`。
