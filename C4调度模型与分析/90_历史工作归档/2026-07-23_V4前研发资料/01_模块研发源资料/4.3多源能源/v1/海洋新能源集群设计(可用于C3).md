# 五、海洋新能源集群设计

## 一、 核心文献提取与数学基础构建

**1. 混合海洋可再生能源空间协同（方向2：空间共享与多源平滑）**

*   **1.1 同场利用空间折减系数**
    在同一海域布置风-光-潮设备，存在海洋空间重叠与尾流/遮挡相互影响。需引入同场利用折减系数。
    $$P_{cluster\_raw} = \sum_{i=1}^{N} P_i \cdot (1 - \delta_{space, i})$$
    *参数说明*：$P_i$为单场场站理论出力；$\delta_{space, i}$为空间折减系数（如光伏布置在风机间距内，受风机尾流湍流影响导致发电损失，通常取3%~8%）。
    *文献来源*：[期刊论文] 中国工程科学 . 2026, 28(03) : 40-53《中国海上多场景综合能源岛发展研究》

*   **1.2 多能时空平滑与变异系数**
    风、光、潮流因物理机制不同，其出力峰值在日内存在错位效应。平滑效应可通过集群出力变异系数 $CV$ 量化：
    $$CV = \frac{\sigma(P_{wind} + P_{PV} + P_{tidal})}{\mu(P_{wind} + P_{PV} + P_{tidal})}$$
    *文献来源*：[会议论文] DOI: 10.23919/AEIT63317.2024.10736733（评估混合系统典型气象年的互补特性，证明多源叠加显著降低CV）。

**2. Offshore Energy Hub 物理送出与网络架构（方向1：海缆与氢送出竞争）**

*   **2.1 海缆传输损耗与热约束模型**
    多能汇集至中枢母线后升压送出，交流海缆存在电阻损耗，且受热容限约束。
    $$P_{loss}(t) = I_{cable}^2(t) \cdot R_{cable}(L) = \frac{P_{send}^2(t)}{V^2 \cos^2\varphi} \cdot r_0 \cdot L$$
    $$P_{send}(t) \le S_{cable\_max} \cdot V \cdot \cos\varphi$$
    *参数说明*：$R_{cable}$为海缆总电阻；$r_0$为单位长度电阻；$L$为送电距离；$V$为送电电压；$\cos\varphi$为功率因数；$S_{cable\_max}$为海缆热容量限额。
    *文献来源*：[期刊论文] 电力系统自动化 . 2020, 44(24) : 60-67《基于物质-能量流解析的海上微综合能源系统风险评估》

*   **2.2 电送 vs 氢送（管道/船运）经济性边界模型**
    深远海（>100km）场景下，海缆成本呈非线性急剧上升，需建立“电氢送出临界距离”判据：
    $$C_{cable}(L) = c_1 \cdot L + c_2 \cdot P_{max}$$
    $$C_{H2}(L) = c_3 \cdot P_{electrolyzer} + c_4 \cdot L_{pipe} \text{ (或 } c_5 \cdot V_{ship}\text{)}$$
    *判据*：当 $C_{cable} > C_{H2}$ 时，集群转为就地制氢送出。
    *文献来源*：[期刊论文] DOI: 10.13335/j.1000-3673.pst.2023.1726（含海上风电制氢的综合能源系统分布鲁棒优化运行，探讨送出方式边界）。

*   **2.3 物质-能量流拓扑矩阵**
    定义集群网络节点-支路关联矩阵 $A$，描述能量路由：
    $$A \cdot \mathbf{F} + \mathbf{L} = \mathbf{P}$$
    *参数说明*：$A$为节点关联矩阵（包含拓扑结构）；$\mathbf{F}$为支路传输流向量（海缆功率/氢管流量）；$\mathbf{L}$为节点负荷向量；$\mathbf{P}$为节点注入功率向量。
    *文献来源*：[期刊论文] 电力系统自动化 . 2020, 44(24) : 60-67

## 二、 市场已有集群化应用与参数明确（国内外示范工程检索）

**1. 国内理论实践与参数**
国内目前虽无深远海多能集群送出工程，但正在推进“海上风电+海洋牧场+海上光伏”同场利用试点。

*   **同场利用参数** [来源：中国工程科学. 2026]：空间折减系数 $\delta_{space}$ 综合取值 0.05；多源叠加平滑系数 $\gamma_{smooth}$ 可使峰值功率降低约 15%。
*   **典型海缆参数** [假设值，待企业调研校准]：220kV交流海缆，单位长度电阻 $r_0 = 0.05 \ \Omega/km$，载流量上限 1200A。

**2. 国外示范工程补充：荷兰 PosHYdon 项目**

*   **应用场景**：世界上首个海上绿氢试点项目。在北海改造的天然气平台（Neptune平台）上，接入周围三座海上风电场（共计 >100MW）的部分电力，结合平台天然气电力，就地电解水制氢并送回陆地。
*   **关键参数** [来源：PosHYdon项目白皮书]：
    *   电解槽装机：1 MW（验证阶段）。
    *   送出经济性边界验证：当离岸距离 $L > 80 \text{ km}$ 时，就地制氢并利用现有天然气管网混输的成本开始低于新建交流海缆。

## 三、 完整模型补充：集群网络拓扑优化逻辑

构建完整的集群设计，还需引入**网络拓扑寻优**（如何将风机、光伏、潮流机组用海缆连接至中枢升压站/制氢平台，使总投资最小）。

**1. 最小生成树（MST）拓扑寻优模型**
设节点集合 $V$（包含各发电装备与枢纽节点），边集合 $E$（可能的海缆路径），寻找一棵生成树 $T$ 使建设成本最小：
$$\min \sum_{(i,j) \in T} \left( C_{fix}(i,j) + C_{var}(i,j) \cdot P_{rated}(i,j) \right)$$
$$\text{s.t.} \quad \sum P_{node} \le P_{cable\_limit}$$
*文献来源*：通用海上风电场内部集电系统优化设计理论延展 [需查证文献支撑]。

## 四、 海洋能源集群设计架构

1. **资源与空间布局层** -> 确定风/光/潮场站位置 -> 计算同场利用折减系数 $\delta_{space}$ -> 生成集群原始总功率
2. **多源平滑效应层** -> 多能功率叠加 -> 计算变异系数CV -> 确定合理的集群外送容量（避免按单源峰值叠加导致海缆浪费）
3. **物理网络寻优层** -> 基于MST算法规划内部集电海缆拓扑 -> 选定中枢能源枢纽节点
4. **送出方式决策层** -> 计算临界距离 $L_{crit}$ -> 若 $L < L_{crit}$ 则海缆送电，否则就地制氢/船运或管输

## 五、 MATLAB/Simulink 仿真代码框架

以下代码展示了海洋能源集群的空间平滑计算、海缆损耗以及送出方式的经济性临界判据：

```matlab
% =========================================================================
% 蓝海枢纽 - 海洋能源集群空间协同与物理送出模型框架
% 来源标注：基于PosHYdon项目参数与中国工程科学文献整合
% =========================================================================
clear; clc;

%% 1. 集群参数与环境初始化
% 模拟三个子场站：漂浮风电、光伏、潮流
t_end = 24; dt = 1; t = 1:t_end;
P_wind = 10 + 5*sin(2*pi*t/24);    % MW
P_pv = 8*(sin(pi*(t-6)/12)).^2; P_pv(P_pv<0)=0; % MW
P_tidal = 3 + 2*sin(2*pi*t/12);    % MW

% 空间共享折减系数 [来源: 中国工程科学. 2026]
delta_wind = 0.00; % 风电作为主导，无折减
delta_pv = 0.05;   % 光伏受风机尾流影响折减5%
delta_tidal = 0.03;% 潮流受平台桩基尾流影响折减3%

% 计算折减后集群总功率
P_cluster = P_wind*(1-delta_wind) + P_pv*(1-delta_pv) + P_tidal*(1-delta_tidal);

% 多源平滑效应评估 [来源: DOI: 10.23919/AEIT63317.2024.10736733]
CV_single = std(P_wind) / mean(P_wind); % 单一风能变异系数
CV_multi = std(P_cluster) / mean(P_cluster);
fprintf('单一风电变异系数: %.3f, 多能集群变异系数: %.3f\n', CV_single, CV_multi);

%% 2. 物理送出网络与海缆损耗模型
% 海缆参数 [假设值，待企业调研校准]
V_grid = 220; % kV
cos_phi = 0.95;
r0 = 0.05; % Ohm/km
S_cable_max = 250; % MVA 热容量限值
P_send_max = S_cable_max * cos_phi; % MW

% 距离扫描分析 (0 ~ 150 km)
L_array = 0:10:150;
Cost_cable = zeros(size(L_array));
Cost_H2 = zeros(size(L_array));

% 成本参数 [来源: PosHYdon白皮书延展假设]
c1_cable = 1.5; % 百万元/km (固定与建设成本)
c2_cable = 0.5; % 百万元/MW (容量相关成本)
c3_H2 = 10;     % 百万元/MW (电解槽固定投资分摊)
c4_H2_pipe = 0.8; % 百万元/km (氢气管道假设成本)

% 集群最大外送需求
P_cluster_max = max(P_cluster);

for i = 1:length(L_array)
    L = L_array(i);
    
    % 计算海缆损耗 [来源: 电力系统自动化. 2020]
    P_loss = (P_cluster_max * 1e6)^2 * (r0 * L) / ((V_grid * 1e3)^2 * cos_phi^2) / 1e6; % MW
    
    % 校验热约束
    if (P_cluster_max + P_loss) > P_send_max
        Cost_cable(i) = inf; % 超过海缆热容量，物理不可行
    else
        Cost_cable(i) = c1_cable * L + c2_cable * P_cluster_max;
    end
    
    % 制氢送出成本计算 [来源: DOI: 10.13335/...pst.2023.1726]
    Cost_H2(i) = c3_H2 * P_cluster_max + c4_H2_pipe * L;
end

% 寻找经济性临界距离
idx_cross = find(Cost_H2 < Cost_cable, 1);
if ~isempty(idx_cross)
    fprintf('电-氢送出经济性临界距离约为: %d km\n', L_array(idx_cross));
end

%% 3. 结果可视化
figure;
subplot(2,1,1);
plot(t, P_wind, '--', t, P_pv, '--', t, P_tidal, '--', t, P_cluster, 'k-', 'LineWidth', 2);
title('海洋多能集群空间平滑叠加效应'); legend('风电','光伏','潮流','集群总功率');
ylabel('功率; xlabel('时间;

subplot(2,1,2);
plot(L_array, Cost_cable, 'b-o', L_array, Cost_H2, 'r-s', 'LineWidth', 1.5);
title('深远海能源送出方式经济性边界 (PosHYdon模型)'); legend('海缆送电成本', '就地制氢管输成本');
ylabel('成本(百万元)'); xlabel('离岸距');
```
