# 二、漂浮式光伏模型

## 一、 核心文献提取与数学基础构建

**1. 光伏基础物理模型（方向1：辐照、温度、效率）**
海上光伏的基础光电转换依然遵循半导体光伏效应，输出功率主要受实际辐照度与组件温度影响。
$$P_{PV\_base} = P_{STC} \cdot \frac{G}{G_{STC}} \cdot [1 + \gamma (T_{cell} - T_{STC})]$$
*参数说明*：$P_{PV\_base}$为基础输出功率；$P_{STC}$为标准测试条件（STC）下额定功率；$G$为倾斜面实际接收辐照度；$G_{STC}$为1000 W/m²；$\gamma$为功率温度系数（负值，晶硅通常为-0.35%/℃~ -0.4%/℃）；$T_{cell}$为组件实际工作温度；$T_{STC}$为25℃。
*文献来源*：[期刊论文] 袁田等《京津冀地区湖库漂浮式光伏开发潜力及节水降碳成效》

**2. 海洋环境修正模型（方向2：海水冷却、波浪运动、盐雾腐蚀）**

*   **2.1 海水冷却效应（温度增益模型）**
    由于海水巨大的热容量和蒸发冷却作用，海上光伏组件温度显著低于陆地，从而产生“冷却增益”。
    $$T_{cell\_sea} = T_{air} + k_{sea} \cdot G$$
    *参数说明*：$T_{air}$为环境气温；$k_{sea}$为海上组件温度系数。陆地通常为0.03~0.04 ℃·m²/W，而海上漂浮环境由于水气热交换强烈，$k_{sea}$可降至0.015~0.02 ℃·m²/W。
    *文献来源*：[期刊论文] DOI: 10.27393/d.cnki.gxazu.2023.001159

*   **2.2 波浪运动耦合模型（动态入射角与遮挡修正）**
    波浪运动导致光伏平台产生六自由度摇摆（主要为纵摇Pitch和横摇Roll），改变太阳光入射角；同时极端波浪爬升会造成物理遮挡。其实际有效辐照度需引入波浪修正系数 $k_{wave}$：
    $$G_{eff} = G \cdot k_{wave}(\theta_{pitch}, \theta_{roll}, H_{wave})$$
    $$k_{wave} = \frac{\cos(\theta_{inc} + \theta_{platform})}{\cos(\theta_{inc})} \cdot (1 - \delta_{shade}(H_{wave}))$$
    *参数说明*：$\theta_{inc}$为无波浪时的太阳光入射角；$\theta_{platform}$为由波浪引起的平台倾角（随时间动态变化）；$\delta_{shade}$为极端波高导致的遮挡折损率。
    *文献来源*：[期刊论文] DOI: 10.27360/d.cnki.gtlgy.2025.000626; [期刊论文] DOI: 10.19912/j.0254-0096.tynxb.2024-1992

*   **2.3 盐雾腐蚀与生物污损衰减模型**
    海洋高盐雾环境会导致组件玻璃透光率下降，连接件腐蚀，需引入时间维度的衰减系数 $\eta_{salt}(t)$：
    $$P_{PV\_sea}(t) = P_{PV\_base}(t) \cdot \eta_{salt}(t)$$
    *参数说明*：$\eta_{salt}(t)$为盐雾综合衰减系数，通常呈指数型下降，首年衰减约1.5%~2%，后续逐年衰减0.5%。
    *文献来源*：[期刊论文] DOI: 10.19595/j.cnki.1000-6753.tces.250113

## 三、 完整模型补充与架构逻辑

**补充理论：光伏阵列组串失配模型**
单块组件输出需经过组串并联形成阵列，海洋环境中不同位置的波浪相位差会导致各子阵列动态入射角不一致，引发严重的组串失配损失。
$$P_{array} = \sum_{m=1}^{M} P_{string\_m} \cdot \eta_{inv} - P_{clip}$$
*参数说明*：$M$为组串数；$\eta_{inv}$为逆变器效率；$P_{clip}$为逆变器超载削峰损失。
*文献来源*：[期刊论文] DOI: 10.19595/j.cnki.1000-6753.tces.250113

**完整漂浮光电模型架构（用于协同优化调度输入）：**

1. **天文辐照层** -> 计算太阳高度角/方位角 -> 获取水平面辐照度 $G_{hor}$
2. **波浪动力学层** -> 输入波高/周期 -> 计算平台瞬时倾角 $\theta_{platform}(t)$
3. **海洋环境修正层** -> 计算有效辐照度 $G_{eff}$（波浪修正） -> 计算组件温度 $T_{cell\_sea}$（海水冷却）
4. **电气输出层** -> 计算单组件功率 $P_{PV\_base}$ -> 阵列聚合与逆变器转换 -> 考虑盐雾衰减 $\eta_{salt}$ -> 最终输出 $P_{PV\_sea}$

## 四、 MATLAB/Simulink 仿真代码框架

以下为基于MATLAB Script的底层模型代码，直接反映海洋环境对光伏出力的动态影响：

```matlab
% =========================================================================
% 蓝海枢纽 - 海上漂浮式光伏完整数学模型框架 (以1MW阵列为例)
% 来源标注：基于文献整合，参数参考中石化青岛项目及协鑫组件
% =========================================================================
clear; clc;

%% 1. 参数初始化
% 光伏组件参数 [来源: 协鑫集成]
P_STC = 480;              % 单组件额定功率
N_series = 22;            % 单串组件数
N_parallel = 95;          % 并联支路数 (约1MW阵列)
gamma = -0.0035;          % 功率温度系数 (/℃)
k_sea = 0.018;            % 海上温度系数 (℃·m²/W) [假设值，待企业调研校准]
eta_salt = 0.985;         % 首年盐雾衰减因子
eta_inv = 0.98;           % 逆变器效率
% 环境参数
T_air = 25;               % 环境温度 (℃)
G_STC = 1000;             % 标准辐照度

%% 2. 环境输入设定 (时间序列模拟)
t_end = 120; dt = 0.1; t = 0:dt:t_end;
% 模拟中午强光照，受云层影响波动
G_hor = 900 + 100*sin(2*pi*t/60); % 水平面辐照度 (W/m²)
% 模拟波浪运动 (周期8s，振幅3度引起平台摇摆)
wave_period = 8; 
theta_platform = 3 * pi/180 * sin(2*pi*t/wave_period); % 平台倾角
H_wave = 1.5 + 0.5*sin(2*pi*t/wave_period); % 波高

%% 3. 光伏出力动态计算
P_out = zeros(1, length(t));
T_cell = zeros(1, length(t));
G_eff = zeros(1, length(t));

for i = 1:length(t)
    % [模块A] 波浪入射角修正 [来源: DOI: 10.27360/d.cnki.gtlgy.2025.000626]
    % 假设正午太阳直射，无波浪时入射角为0
    theta_inc = 0; 
    cos_loss = cos(theta_inc + theta_platform(i)) / cos(theta_inc);
    
    % 波浪遮挡修正 (波高超阈值时产生轻微遮挡)
    if H_wave(i) > 2.0
        shade_loss = 0.05 * (H_wave(i) - 2.0); % 简化线性模型
    else
        shade_loss = 0;
    end
    G_eff(i) = G_hor(i) * max(0, cos_loss) * (1 - shade_loss);
    
    % [模块B] 海水冷却温度模型 [来源: DOI: 10.27393/d.cnki.gxazu.2023.001159]
    T_cell(i) = T_air + k_sea * G_eff(i);
    
    % [模块C] 基础物理输出模型 [来源: 袁田等期刊论文]
    P_module = P_STC * (G_eff(i) / G_STC) * (1 + gamma * (T_cell(i) - 25));
    
    % [模块D] 阵列聚合与海洋衰减 [来源: DOI: 10.19595/j.cnki.1000-6753.tces.250113]
    P_array = P_module * N_series * N_parallel * eta_inv * eta_salt;
    
    % 削峰限制 (逆变器容量限制)
    P_out(i) = min(P_array, 1e6); 
end

%% 4. 结果可视化
figure;
subplot(3,1,1);
plot(t, G_hor, 'b', t, G_eff, 'r--'); title('有效辐照度修正对比'); ylabel('W/m²');
legend('原始水平辐照', '波浪修正后有效辐照');

subplot(3,1,2);
plot(t, T_cell, 'r'); title('组件温度 (受海水冷却影响)'); ylabel('温度 (℃)');

subplot(3,1,3);
plot(t, P_out/1e6, 'k'); title('光伏阵列输出功率'); ylabel('功率');
xlabel('时间');
```
