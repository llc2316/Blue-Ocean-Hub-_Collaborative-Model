### 一、漂浮式风电模型

#### 一、 风机空气动力学与出力模型（方向A）

**1. 风速输入与环境模型**
风资源建模需考虑垂直高度切变效应，风速随高度变化的模型通常采用指数律：
$$v(h) = v_{ref} \left( \frac{h}{h_{ref}} \right)^\alpha$$
*参数说明*：$v(h)$为高度$h$处风速；$v_{ref}$为参考高度$h_{ref}$处风速；$\alpha$为风切变指数（海上通常取0.08~0.12，[假设值，待企业调研校准]）。
*文献来源*：[期刊论文] DOI: 10.3969/j.issn.1002-6339.2012.01.006

**2. 叶轮空气动力学功率与转矩模型**
风轮捕获的气动功率与转矩是构建MATLAB风力机特性仿真模块的核心，基于叶素动量理论（BEM）的简化宏观模型如下：
$$P = \frac{1}{2} \rho \pi R^2 v^3 C_p(\lambda, \beta)$$
$$T = \frac{P}{\omega} = \frac{1}{2} \rho \pi R^3 v^2 C_T(\lambda, \beta) / \lambda$$
*参数说明*：$P$为气动功率；$\rho$为空气密度；$R$为叶轮半径；$v$为等效轮毂高度风速；$C_p$为风能利用系数（是叶尖速比$\lambda$和桨距角$\beta$的函数）；$T$为气动转矩；$\omega$为风轮角速度；$C_T$为转矩系数。其中叶尖速比 $\lambda = \frac{\omega R}{v}$。
*文献来源*：[期刊论文] DOI: 10.3969/j.issn.1002-6339.2012.01.006; [期刊论文] DOI: 10.13788/j.cnki.cbgc.2020.S1.128

**3. 机组效率与发电功率约束**
考虑传动系统效率$\eta$及发电机损耗后，实际并网端电功率输出需满足上下限约束：
$$P_e = \eta P \quad (v_{cut\_in} \le v \le v_{rated})$$
$$P_e = P_{rated} \quad (v_{rated} \le v \le v_{cut\_out})$$
$$P_e = 0 \quad (v < v_{cut\_in} \text{ 或 } v > v_{cut\_out})$$

*参数说明*：$P_e$为机组输出电功率；$\eta$为传动与发电综合效率；$v_{cut\_in}, v_{rated}, v_{cut\_out}$​​分别为切入、额定、切出风速。
*文献来源*：[期刊论文] DOI: 10.13788/j.cnki.cbgc.2020.S1.128

**4. 传动系统双质块模型** 

风轮侧与发电机侧通过柔性轴连接，存在扭转振动，是引发风电功率低频波动的关键环节。

$\dot{J}_{rωr}=T_{a}−Ks(θr−θg)−B_{s}(ωr−ωg)$

$\dot{J}_{gωg}=Ks(θr−θg)+Bs(ωr−ωg)−Tg$ 

*参数说明*：Jr,Jg分别为风轮和发电机转动惯量；ωr,ωg为转速；θr,θg为扭转角；Ks*,*Bs为刚度与阻尼系数；Ta为气动转矩；Tg为发电机电磁转矩。 *文献来源*：[核心期刊论文] DOI: 10.13788/j.cnki.cbgc.2020.S1.128（大型风电机组通常采用双质块或三质块模型）。

**5. 最大功率点跟踪（MPPT）与转矩控制（额定风速以下）** 通过调节发电机电磁转矩使风机维持在最佳叶尖速比：

$T_{g_ref}=k_{opt}ω_{g}^2, k_{opt}=\frac{1}{2}ρπR^5\frac{C_{p_max}}{λ_{opt3}}$

*文献来源*：[核心期刊论文] 风电机组传统线性/非线性控制文献通用模型。

**6. 变桨距控制（额定风速以上）** 为限制功率超限，采用PI控制器调节桨距角：

$β_{ref}=K_{ppitch}(P_{e}−P_{rated})+K_{ipitch}∫(P_{e}−P_{rated})dt$

$\dot{β}=\frac{1}{τ_{β}}(β_{ref}−β)$(执行机构限幅：±8∘/s,幅度0∼30∘)

*文献来源*：[学位论文] DOI: 10.27670/d.cnki.gcqdu.2022.001037

#### 二、 浮式平台耦合与水动力模型（方向B）

漂浮式风机区别于固定式底座的核心在于平台六自由度（6-DOF）运动产生的额外气弹耦合效应，这会导致等效风速发生变化，进而引起功率波动。

**1. 平台六自由度运动方程**
基于刚体动力学与势流理论，浮式平台在风、浪、流联合作用下的6-DOF运动方程为：
$$[M + A(\omega)]\ddot{X} + B(\omega)\dot{X} + CX = F_{wind} + F_{wave} + F_{mooring}$$
*参数说明*：$M$为系统广义质量矩阵；$A(\omega)$为附加质量矩阵；$B(\omega)$为辐射阻尼矩阵；$C$为静水回复刚度矩阵；$X, \dot{X}, \ddot{X}$分别为6个自由度（纵荡Surge、横荡Sway、垂荡Heave、横摇Roll、纵摇Pitch、首摇Yaw）的位移、速度、加速度向量；$F_{wind}$为风载荷；$F_{wave}$为波浪载荷；$F_{mooring}$为系泊力。
*文献来源*：[学位论文] DOI: 10.27140/d.cnki.ghbbu.2024.002290; [学位论文] DOI: 10.27140/d.cnki.ghbbu.2025.000289

**2. 波浪载荷模型**
对于支柱式或半潜式浮体，波浪激振力通常采用Morison方程与势流理论结合：
$$F_{wave} = \rho C_M \frac{\pi}{4} D^2 \dot{u} + \frac{1}{2} \rho C_D D |u| u$$
*参数说明*：$C_M$为惯性力系数；$C_D$为拖曳力系数；$D$为平台支柱特征直径；$u, \dot{u}$分别为水质点速度与加速度。
*文献来源*：[学位论文] DOI: 10.27140/d.cnki.ghbbu.2025.000289

**3. 系泊系统恢复力模型**
系泊缆索对浮体的非线性恢复力可通过准静态悬链线方程或集中质量法描述：
$$F_{mooring} = f(X, L_{cable}, W_{cable}, E_{cable})$$
*参数说明*：$L_{cable}$为缆索长度，$W_{cable}$为单位长度湿重，$E_{cable}$为弹性模量。在简化调度模型中可线性化为刚度矩阵 $K_{moor} X$ [需查证文献支撑]。
*文献来源*：[学位论文] DOI: 10.27140/d.cnki.ghbbu.2024.000436

#### 三、 平台运动与气动耦合效应（功率波动修正）

平台纵摇和纵荡运动会改变叶片局部的相对风速和攻角，这是漂浮式风电功率波动的核心来源。

**1. 等效轮毂风速修正模型**
平台运动导致的等效风速变化可线性叠加为：
$$v_{eff} = v_{hub} - \dot{x}_{surge} - \dot{\theta}_{pitch} H_{hub}$$
*参数说明*：$v_{eff}$为耦合后的等效风速；$v_{hub}$为环境来流风速；$\dot{x}_{surge}$为平台纵荡速度；$\dot{\theta}_{pitch}$为平台纵摇角速度；$H_{hub}$为轮毂距水线高度。
*文献来源*：[学位论文] DOI: 10.27140/d.cnki.ghbbu.2024.002290; [学位论文] DOI: 10.27670/d.cnki.gcqdu.2022.001037

**2. 修正后的机组输出功率模型**
将等效风速代入方向A的功率模型，并引入动态入流带来的$C_p$损失系数$\Delta C_p$：
$$P_{float} = \frac{1}{2} \rho \pi R^2 v_{eff}^3 \left[ C_p(\lambda_{eff}, \beta) - \Delta C_p(\dot{\theta}_{pitch}) \right]$$
*参数说明*：$\lambda_{eff}$为基于$v_{eff}$更新的叶尖速比；$\Delta C_p$为由于平台复杂运动引起的动态气动损失项。
*文献来源*：[学位论文] DOI: 10.27140/d.cnki.ghbbu.2024.002290

#### 四、 风电场级出力特性与预测模型（多源集成准备）

**1. 风电场出力空间平滑效应**
多机组聚合后的功率输出小于单机代数和，需考虑尾流效应与空间平滑系数：
$$P_{farm} = \sum_{i=1}^{N} P_{i} \times (1 - \delta_{wake}) \times \gamma_{smooth}$$
*参数说明*：$N$为风机台数；$\delta_{wake}$为尾流折减系数；$\gamma_{smooth}$为空间平滑系数（与风向、机组间距相关，通常取0.85~0.95，[假设值，待企业调研校准]）。
*文献来源*：[期刊论文] 叶剑, 袁智强《上海电网并网风电场出力特性分析》

**2. 短期功率预测-校正模型**
针对海上风电高波动性，采用基于机组分类（如按容量/位置/机型分群）的误差校正预测模型框架：
$$\hat{P}_{t+k}^{corrected} = \hat{P}_{t+k}^{base} + \sum_{j=1}^{m} \alpha_j \epsilon_{t-k_j}^{(j)}$$
*参数说明*：$\hat{P}_{t+k}^{base}$为基础预测值（如NWP驱动）；$\epsilon_{t-k_j}^{(j)}$为第$j$类机组在历史时刻$t-k_j$的预测误差；$\alpha_j$为自适应权重系数。
*文献来源*：[期刊论文] 祁乐等《考虑机组分类的海上风电短期功率预测-校正模型》

综合上述提取内容，构建面向“蓝海枢纽”的完整风机模型架构如下：

**【环境输入层】** -> 风速序列 v**h**u**b + 波浪谱 F**w**a**v**e **

【平台水动力层】 -> 6-DOF运动方程 -> 提取纵荡速度$\dot{x}_{surge} $和纵摇角速度$\dot{θ}_{pitch}$ 

 **【气动耦合层】** -> 等效风速修正veff=vhub−$\dot{x}_{surge} $−$\dot{θ}_{pitch}\times$ Hhub-> 计算 $C_{p}(λeff,β)$ -> 气动转矩 Ta

【传动控制层】 -> 双质块动态方程计算 ωr,ωg -> MPPT/变桨控制器输出 Tg_ref,βref

 **【电气输出层】** -> 发电机电磁转矩 Tg 与转速 ωg -> 输出电功率 $Pe=T_{gωg}η_{gen}$（并考虑切出逻辑）

#### 八、 MATLAB/Simulink 仿真代码框

以下为基于MATLAB Script的数学模型底层代码框架（可直接转化为Simulink的S-Function或M-Script），展示核心微分方程求解逻辑：

```shell
% =========================================================================
% 蓝海枢纽 - 漂浮式风电完整数学模型框架 (16MW半潜式机组基准)
% 来源标注：基于文献整合，参数明阳MySE16.0-260
% =========================================================================
clear; clc;

%% 1. 参数初始化 [来源: 明阳智能官网/文献]
% 气动参数
Prated = 16e6; R = 130; v_ci = 3; v_r = 10.5; v_co = 25;
rho = 1.225; Cp_max = 0.48; lambda_opt = 8.5;
% 传动参数 [假设值，待企业调研校准]
Jr = 1e7; Jg = 1e6; Ks = 1e8; Bs = 1e5; N_gear = 1; % 直驱模型
% 平台参数 [来源: DOI: 10.27140/d.cnki.ghbbu.2024.002290]
H_hub = 150; 
% 控制参数 [来源: DOI: 10.27670/d.cnki.gcqdu.2022.001037]
k_opt = 0.5 * rho * pi * R^5 * Cp_max / (lambda_opt^3);
Kp_pitch = 1e4; Ki_pitch = 1e3; tau_beta = 0.1; 

%% 2. 环境输入设定 (假设时间序列)
t_end = 100; dt = 0.01; t = 0:dt:t_end;
v_wind = 11 + 1.5*sin(2*pi*t/20); % 额定附近波动风速 m/s
F_wave = 5e5 * sin(2*pi*t/30);    % 简化波浪激振力 N

%% 3. 状态变量初始化
% 状态: [x_surge_dot; theta_pitch_dot; x_surge; theta_pitch; omega_r; omega_g; theta_r; theta_g; beta]
X = zeros(9, length(t));
X(1,1) = 0; % 初始纵荡速度
X(5,1) = 0.8; % 初始风轮转速 rad/s

%% 4. 核心动力学求解 (使用ODE45或欧拉法迭代)
for i = 1:length(t)-1
    % 当前状态提取
    x_surge_dot = X(1,i); theta_pitch_dot = X(2,i);
    omega_r = X(5,i); omega_g = X(6,i); beta = X(9,i);
    
    % [模块A] 平台运动简化模型 (等效一阶振荡)
    % 实际应调用6-DOF质量阻尼矩阵，此处简化提取文献中的运动响应
    % [来源: DOI: 10.27140/d.cnki.ghbbu.2025.000289]
    dx_surge = x_surge_dot;
    dtheta_pitch = theta_pitch_dot;
    % 注: 简化模型，未严格展开M与C矩阵，实际需带入势流数据
    ddx_surge = (F_wave(i) - 1e5*x_surge_dot - 1e4*X(3,i)) / 1e7; 
    ddtheta_pitch = (5e6*F_wave(i) - 1e7*theta_pitch_dot - 1e6*X(4,i)) / 1e9;
    
    % [模块B] 等效风速计算 [来源: DOI: 10.27140/d.cnki.ghbbu.2024.002290]
    v_hub = v_wind(i);
    v_eff = v_hub - x_surge_dot - theta_pitch_dot * H_hub;
    if v_eff < v_ci || v_eff > v_co
        Pe = 0; Ta = 0;
    else
        % [模块C] 气动计算 [来源: DOI: 10.3969/j.issn.1002-6339.2012.01.006]
        lambda_eff = (omega_r * R) / v_eff;
        % 简化C_p计算公式 (实际需查表或高阶拟合)
        Cp = Cp_max * (1 - (lambda_eff - lambda_opt)^2 / 100) * cos(beta)^2; 
        Ta = 0.5 * rho * pi * R^3 * v_eff^2 * Cp / lambda_eff;
        Pe = Ta * omega_r; % 简化机械功率到电气功率
    end
    
    % [模块D] 控制策略 [来源: 通用模型]
    if v_eff < v_r
        % MPPT转矩控制
        Tg_ref = k_opt * omega_g^2;
        beta_ref = 0;
    else
        % 变桨距功率控制
        Tg_ref = Prated / omega_g;
        beta_ref = beta + dt * (Kp_pitch*(Pe-Prated) + Ki_pitch*(Pe-Prated)*dt);
        beta_ref = max(0, min(30, beta_ref));
    end
    
    % [模块E] 传动系统双质块模型 [来源: DOI: 10.13788/j.cnki.cbgc.2020.S1.128]
    Ts = Ks*(X(7,i)-X(8,i)) + Bs*(omega_r - omega_g);
    domega_r = (Ta - Ts) / Jr;
    domega_g = (Ts - Tg_ref) / Jg; % 假设电磁转矩响应无延迟
    dtheta_r = omega_r;
    dtheta_g = omega_g;
    
    % 变桨执行机构
    dbeta = (beta_ref - beta) / tau_beta;
    
    % 状态更新 (欧拉法)
    X(1,i+1) = X(1,i) + dx_surge*dt;
    X(2,i+1) = X(2,i) + dtheta_pitch*dt;
    X(3,i+1) = X(3,i) + ddx_surge*dt;
    X(4,i+1) = X(4,i) + ddtheta_pitch*dt;
    X(5,i+1) = X(5,i) + domega_r*dt;
    X(6,i+1) = X(6,i) + domega_g*dt;
    X(7,i+1) = X(7,i) + dtheta_r*dt;
    X(8,i+1) = X(8,i) + dtheta_g*dt;
    X(9,i+1) = X(9,i) + dbeta*dt;
end

%% 5. 输出结果可视化
P_out = X(5,:) .* X(6,:) * 0.95; % 简化输出功率计算
figure;
plot(t, v_wind, 'b'); hold on; yyaxis right; plot(t, P_out/1e6, 'r');
title('漂浮式风机风速与功率响应'); xlabel('时间; legend('风速', '输出功率(MW)');
```

### 二、漂浮式光伏模型

#### 一、 核心文献提取与数学基础构建

**1. 光伏基础物理模型（方向1：辐照、温度、效率）**
海上光伏的基础光电转换依然遵循半导体光伏效应，输出功率主要受实际辐照度与组件温度影响。
$$P_{PV\_base} = P_{STC} \cdot \frac{G}{G_{STC}} \cdot [1 + \gamma (T_{cell} - T_{STC})]$$
*参数说明*：$P_{PV\_base}$为基础输出功率；$P_{STC}$为标准测试条件（STC）下额定功率；$G$为倾斜面实际接收辐照度；$G_{STC}$为1000 W/m²；$\gamma$为功率温度系数（负值，晶硅通常为-0.35%/℃~ -0.4%/℃）；$T_{cell}$为组件实际工作温度；$T_{STC}$为25℃。
*文献来源*：[期刊论文] 袁田等《京津冀地区湖库漂浮式光伏开发潜力及节水降碳成效》

**2. 海洋环境修正模型（方向2：海水冷却、波浪运动、盐雾腐蚀）**

*   **2.1 海水冷却效应（温度增益模型）**
由于海水巨大的热容量和蒸发冷却作用，海上光伏组件温度显著低于陆地，从而产生“冷却增益”。
$$T_{cell\_sea} = T_{air} + k_{sea} \cdot G$$
*参数说明*：$T_{air}$为环境气温；$k_{sea}$为海上组件温度系数。陆地通常为0.03~0.04 ℃·m²/W，而海上漂浮环境由于水气热交换强烈，$k_{sea}$可降至0.015~0.02 ℃·m²/W。
*文献来源*：[期刊论文] DOI: 10.27393/d.cnki.gxazu.2023.001159

*   **2.2 波浪运动耦合模型（动态入射角与遮挡修正）**
波浪运动导致光伏平台产生六自由度摇摆（主要为纵摇Pitch和横摇Roll），改变太阳光入射角；同时极端波浪爬升会造成物理遮挡。其实际有效辐照度需引入波浪修正系数 $k_{wave}$：
$$G_{eff} = G \cdot k_{wave}(\theta_{pitch}, \theta_{roll}, H_{wave})$$
$$k_{wave} = \frac{\cos(\theta_{inc} + \theta_{platform})}{\cos(\theta_{inc})} \cdot (1 - \delta_{shade}(H_{wave}))$$
*参数说明*：$\theta_{inc}$为无波浪时的太阳光入射角；$\theta_{platform}$为由波浪引起的平台倾角（随时间动态变化）；$\delta_{shade}$为极端波高导致的遮挡折损率。
*文献来源*：[期刊论文] DOI: 10.27360/d.cnki.gtlgy.2025.000626; [期刊论文] DOI: 10.19912/j.0254-0096.tynxb.2024-1992

*   **2.3 盐雾腐蚀与生物污损衰减模型**
海洋高盐雾环境会导致组件玻璃透光率下降，连接件腐蚀，需引入时间维度的衰减系数 $\eta_{salt}(t)$：
$$P_{PV\_sea}(t) = P_{PV\_base}(t) \cdot \eta_{salt}(t)$$
*参数说明*：$\eta_{salt}(t)$为盐雾综合衰减系数，通常呈指数型下降，首年衰减约1.5%~2%，后续逐年衰减0.5%。
*文献来源*：[期刊论文] DOI: 10.19595/j.cnki.1000-6753.tces.250113

#### 三、 完整模型补充与架构逻辑

**补充理论：光伏阵列组串失配模型**
单块组件输出需经过组串并联形成阵列，海洋环境中不同位置的波浪相位差会导致各子阵列动态入射角不一致，引发严重的组串失配损失。
$$P_{array} = \sum_{m=1}^{M} P_{string\_m} \cdot \eta_{inv} - P_{clip}$$
*参数说明*：$M$为组串数；$\eta_{inv}$为逆变器效率；$P_{clip}$为逆变器超载削峰损失。
*文献来源*：[期刊论文] DOI: 10.19595/j.cnki.1000-6753.tces.250113

**完整漂浮光电模型架构（用于协同优化调度输入）：**
1. **天文辐照层** -> 计算太阳高度角/方位角 -> 获取水平面辐照度 $G_{hor}$
2. **波浪动力学层** -> 输入波高/周期 -> 计算平台瞬时倾角 $\theta_{platform}(t)$
3. **海洋环境修正层** -> 计算有效辐照度 $G_{eff}$（波浪修正） -> 计算组件温度 $T_{cell\_sea}$（海水冷却）
4. **电气输出层** -> 计算单组件功率 $P_{PV\_base}$ -> 阵列聚合与逆变器转换 -> 考虑盐雾衰减 $\eta_{salt}$ -> 最终输出 $P_{PV\_sea}$

#### 四、 MATLAB/Simulink 仿真代码框架

以下为基于MATLAB Script的底层模型代码，直接反映海洋环境对光伏出力的动态影响：

```matlab
% =========================================================================
% 蓝海枢纽 - 海上漂浮式光伏完整数学模型框架 (以1MW阵列为例)
% 来源标注：基于文献整合，参数参考中石化青岛项目及协鑫组件
% =========================================================================
clear; clc;

%% 1. 参数初始化
% 光伏组件参数 [来源: 协鑫集成]
P_STC = 480;              % 单组件额定功率
N_series = 22;            % 单串组件数
N_parallel = 95;          % 并联支路数 (约1MW阵列)
gamma = -0.0035;          % 功率温度系数 (/℃)
k_sea = 0.018;            % 海上温度系数 (℃·m²/W) [假设值，待企业调研校准]
eta_salt = 0.985;         % 首年盐雾衰减因子
eta_inv = 0.98;           % 逆变器效率
% 环境参数
T_air = 25;               % 环境温度 (℃)
G_STC = 1000;             % 标准辐照度

%% 2. 环境输入设定 (时间序列模拟)
t_end = 120; dt = 0.1; t = 0:dt:t_end;
% 模拟中午强光照，受云层影响波动
G_hor = 900 + 100*sin(2*pi*t/60); % 水平面辐照度 (W/m²)
% 模拟波浪运动 (周期8s，振幅3度引起平台摇摆)
wave_period = 8; 
theta_platform = 3 * pi/180 * sin(2*pi*t/wave_period); % 平台倾角
H_wave = 1.5 + 0.5*sin(2*pi*t/wave_period); % 波高

%% 3. 光伏出力动态计算
P_out = zeros(1, length(t));
T_cell = zeros(1, length(t));
G_eff = zeros(1, length(t));

for i = 1:length(t)
    % [模块A] 波浪入射角修正 [来源: DOI: 10.27360/d.cnki.gtlgy.2025.000626]
    % 假设正午太阳直射，无波浪时入射角为0
    theta_inc = 0; 
    cos_loss = cos(theta_inc + theta_platform(i)) / cos(theta_inc);
    
    % 波浪遮挡修正 (波高超阈值时产生轻微遮挡)
    if H_wave(i) > 2.0
        shade_loss = 0.05 * (H_wave(i) - 2.0); % 简化线性模型
    else
        shade_loss = 0;
    end
    G_eff(i) = G_hor(i) * max(0, cos_loss) * (1 - shade_loss);
    
    % [模块B] 海水冷却温度模型 [来源: DOI: 10.27393/d.cnki.gxazu.2023.001159]
    T_cell(i) = T_air + k_sea * G_eff(i);
    
    % [模块C] 基础物理输出模型 [来源: 袁田等期刊论文]
    P_module = P_STC * (G_eff(i) / G_STC) * (1 + gamma * (T_cell(i) - 25));
    
    % [模块D] 阵列聚合与海洋衰减 [来源: DOI: 10.19595/j.cnki.1000-6753.tces.250113]
    P_array = P_module * N_series * N_parallel * eta_inv * eta_salt;
    
    % 削峰限制 (逆变器容量限制)
    P_out(i) = min(P_array, 1e6); 
end

%% 4. 结果可视化
figure;
subplot(3,1,1);
plot(t, G_hor, 'b', t, G_eff, 'r--'); title('有效辐照度修正对比'); ylabel('W/m²');
legend('原始水平辐照', '波浪修正后有效辐照');

subplot(3,1,2);
plot(t, T_cell, 'r'); title('组件温度 (受海水冷却影响)'); ylabel('温度 (℃)');

subplot(3,1,3);
plot(t, P_out/1e6, 'k'); title('光伏阵列输出功率'); ylabel('功率');
xlabel('时间');
```

#### 二、 核心文献提取与数学基础构建

**1. 潮流资源评估与输入模型（IEC TS 62600-201对齐）**
潮流流速具有极强的周期性规律，且垂向存在流速剪切。基于FVCOM海洋模型数值模拟结果，流速随深度的变化遵循1/7次方律：
$$v(z) = v_{ref} \left( \frac{z}{z_{ref}} \right)^{1/7}$$
*参数说明*：$v(z)$为距海底高度$z$处的流速；$v_{ref}$为参考高度$z_{ref}$处的平均流速。水轮机轮毂高度处的等效流速需积分平均。
*文献来源*：[学位论文] DOI: 10.27356/d.cnki.gtjdu.2021.004112; [期刊论文] 分类号: P743;TM612

**2. 水轮机水动力捕获模型（装备驱动核心）**
与风电类似，基于叶素动量理论（BEM），水平轴水轮机捕获的机械功率与转矩为：
$$P_{mech} = \frac{1}{2} \rho \pi R^2 v^3 C_p(\lambda, \theta)$$
$$T_{hydro} = \frac{P_{mech}}{\omega} = \frac{1}{2} \rho \pi R^3 v^2 C_T(\lambda, \theta) / \lambda$$
*参数说明*：$\rho$为水密度（约为空气的800倍，故低速下扭矩极大）；$C_p$为水动力捕获系数；$\lambda = \frac{\omega R}{v}$为叶尖速比；$\theta$为桨距角。
*文献来源*：[期刊论文] 分类号: P743.3《水平轴潮流能水轮机水动力数值模拟研究》

**3. 桩基与平台尾流扰动损失模型**
单桩式支撑结构会引起流场收缩和尾流扰动，导致实际捕获功率下降。需引入桩基影响折减系数 $\eta_{pile}$（通常取0.92~0.96 [需查证文献支撑]）：
$$P_{actual} = \eta_{pile} \cdot P_{mech}$$
*文献来源*：[期刊论文] 分类号: P743.1《单桩式水平轴潮流能机组桩基影响研究》

**4. 发电性能评估优化（数据驱动修正）**
针对实海况下流速波动与机组响应延迟，IEC TS 62600-201及GB/Z 37551.300-2026要求引入数据插值算法对功率曲线进行非线性优化拟合：
$$P_{out}(v) = f_{interp}(v_{measured}, P_{measured}, \Delta t_{response})$$
*文献来源*：[期刊论文] DOI: 10.19650/j.cnki.cjsi.J2514328; [国家标准] GB/Z 37551.300-2026

---

#### 三、 完整模型补充：传动与控制策略逻辑

由于水的不可压缩性，波浪与湍流会对水轮机产生极大的瞬态冲击载荷，必须在模型中补充**传动系统柔性缓冲**与**变桨/变流控制**。

**1. 传动系统模型**
与风机类似，采用双质块模型解耦水轮机侧与发电机侧，保护齿轮箱免受瞬态水动力冲击：
$$J_h \dot{\omega}_h = T_{hydro} - K_s(\theta_h - \theta_g) - B_s(\omega_h - \omega_g)$$
$$J_g \dot{\omega}_g = K_s(\theta_h - \theta_g) + B_s(\omega_h - \omega_g) - T_g$$
*文献来源*：[期刊论文] 分类号: TM312;TV131.2（类比支撑平台动力学模型延展）

**2. 控制策略：跨额定流速变桨控制**
当流速超过额定流速时，通过变桨距调节限制捕获功率，保护发电机：
*   $v < v_{rated}$：MPPT控制，$T_{g\_ref} = k_{opt} \omega_g^2$
*   $v \ge v_{rated}$：变桨控制，$\theta_{ref} = K_p(P_e - P_{rated}) + K_i \int(P_e - P_{rated}) dt$

---

#### 四、 漂浮/海底潮流能发电模型架构

1. **潮流资源输入层** -> 基于FVCOM模型获取天文潮汐预报序列 -> 引入1/7次方垂向剪切修正 -> 计算轮毂高度等效流速 $v(t)$
2. **水动力捕获层** -> 计算 $\lambda(t)$ -> 查询/计算 $C_p(\lambda, \theta)$ -> 乘以水密度与截面积 -> 获取水轮机轴端机械功率 $P_{mech}$
3. **结构修正层** -> 桩基/支撑结构尾流损失系数 $\eta_{pile}$ -> 平台运动（如有）导致的附加迎流速度修正
4. **传动控制层** -> 双质块扭振滤波 -> MPPT或变桨控制指令下发 -> 电磁转矩 $T_g$ 跟踪
5. **电气输出层** -> 发电机效率 $\eta_{gen}$ -> 变流器并网/离网输出 $P_{out}$

#### 五、 MATLAB/Simulink 仿真代码框架

以下为基于MATLAB Script的潮流能底层物理模型代码，展示了潮汐周期特性与装备控制逻辑：

```matlab
% =========================================================================
% 蓝海枢纽 - 潮流能发电机组完整数学模型框架 (LHD 1.5MW基准)
% 来源标注：基于文献与LHD实机参数整合
% =========================================================================
clear; clc;

%% 1. 参数初始化
% 水轮机装备参数 [来源: LHD项目/文献整合]
Prated = 1.5e6; R = 8.5; rho = 1025; 
v_ci = 1.0; v_r = 2.8; % 切入/额定流速
Cp_max = 0.42; lambda_opt = 6.0;
eta_pile = 0.94; % 桩基折减 [需查证文献支撑]
eta_gen = 0.95;  % 机电转换效率
% 传动参数 (由于水力扭矩大，转动惯量与刚度大于风机) [假设值，待企业调研校准]
Jh = 5e5; Jg = 5e4; Ks = 1e7; Bs = 1e4; 
% 控制参数
k_opt = 0.5 * rho * pi * R^5 * Cp_max / (lambda_opt^3);
Kp_pitch = 5e5; Ki_pitch = 5e3; 

%% 2. 潮汐流速输入设定 (模拟半日潮周期 12.4小时，这里压缩为分钟级演示)
t_end = 300; dt = 0.1; t = 0:dt:t_end;
% 潮汐流速：正弦波 + 湍流脉动
v_tide = 2.5 + 1.0*sin(2*pi*t/150) + 0.1*randn(size(t)); 

%% 3. 状态变量初始化
X = zeros(4, length(t)); % [omega_h, omega_g, theta_h, theta_g]
beta = zeros(1, length(t));
P_out = zeros(1, length(t));
X(2,1) = 2.0; % 初始发电机转速

%% 4. 核心动力学求解
for i = 1:length(t)-1
    v = v_tide(i);
    omega_h = X(1,i); omega_g = X(2,i);
    
    % [模块A] 水动力捕获计算 [来源: 分类号 P743.3]
    if v < v_ci
        Cp = 0; P_mech = 0;
    else
        lambda = (omega_h * R) / v;
        % 简化C_p计算模型 (考虑变桨角影响)
        Cp = Cp_max * (1 - (lambda - lambda_opt)^2 / 20) * cos(beta(i))^2; 
        P_mech = 0.5 * rho * pi * R^2 * v^3 * Cp * eta_pile;
        if P_mech > Prated / eta_gen
            P_mech = Prated / eta_gen; % 物理限幅
        end
    end
    T_hydro = P_mech / max(omega_h, 0.1); % 防止除零
    
    % [模块B] 控制策略 [来源: 通用变桨/MPPT逻辑]
    P_e = T_hydro * omega_h * eta_gen; % 简化当前功率估算
    if v < v_r && P_e < Prated
        Tg_ref = k_opt * omega_g^2; % MPPT
        beta_ref = 0;
    else
        Tg_ref = Prated / max(omega_g, 0.1); % 限功率
        beta_ref = beta(i) + dt * (Kp_pitch*(P_e-Prated) + Ki_pitch*(P_e-Prated)*dt);
        beta_ref = max(0, min(25, beta_ref)); % 桨距角限幅 0~25度
    end
    
    % [模块C] 传动系统双质块 [来源: TM312;TV131.2]
    Ts = Ks*(X(3,i)-X(4,i)) + Bs*(omega_h - omega_g);
    domega_h = (T_hydro - Ts) / Jh;
    domega_g = (Ts - Tg_ref) / Jg;
    dtheta_h = omega_h;
    dtheta_g = omega_g;
    
    % 状态更新
    X(1,i+1) = X(1,i) + domega_h*dt;
    X(2,i+1) = X(2,i) + domega_g*dt;
    X(3,i+1) = X(3,i) + dtheta_h*dt;
    X(4,i+1) = X(4,i) + dtheta_g*dt;
    beta(i+1) = beta_ref;
    P_out(i+1) = min(Tg_ref * omega_g * eta_gen, Prated);
end

%% 5. 结果可视化
figure;
subplot(2,1,1);
plot(t, v_tide, 'b'); title('LHD项目模拟潮流流速输入'); ylabel('流速; 
subplot(2,1,2);
plot(t, P_out/1e6, 'r'); title('潮流能机组输出功率'); ylabel('功率');
xlabel('时间');
```

### 四、多能源互补系统

#### 一、 核心文献提取与数学基础构建

**1. 多能源联合概率与预测模型（方向1）**
海洋风、光、潮流能具有强随机性和时空耦合性。单一预测模型无法满足多时间尺度调度需求。

*   **1.1 预测算法优选（LSTM对比ARIMA）**
对于海洋多源非平稳序列，ARIMA线性模型在剧烈天气波动下误差累积严重；而长短期记忆网络（LSTM）通过门控机制能有效捕捉时间序列的长期依赖与非线性特征。
$$f_t = \sigma(W_f \cdot [h_{t-1}, x_t] + b_f)$$
$$i_t = \sigma(W_i \cdot [h_{t-1}, x_t] + b_i)$$
$$h_t = (1 - f_t) \odot h_{t-1} + i_t \odot \tanh(W_c \cdot [h_{t-1}, x_t] + b_c)$$
*参数说明*：$f_t, i_t$为遗忘门与输入门；$h_t$为隐藏层状态；$x_t$为多源气象/流速输入。
*文献来源*：[会议论文] DOI: 10.1109/PARC68365.2026.11453600（指出LSTM在多能系统高级管理策略中的优越性）。

*   **1.2 多能时空相关性：Copula联合分布模型**
风-光-潮流出力之间存在非线性相依结构（如大风伴随大浪，但与光照往往负相关）。采用Copula函数构建多源出力的联合概率分布，以量化平滑效应：
$$F(x_1, x_2, x_3) = C(F_1(x_1), F_2(x_2), F_3(x_3); \theta)$$
*参数说明*：$F_i(x_i)$为各能源边缘分布函数（通常为威布尔分布）；$C(\cdot)$为Copula连接函数（常用t-Copula捕捉尾部相关性）；$\theta$为相关参数。
*文献来源*：[期刊论文] DOI: 10.16085/j.issn.1000-6613.2023-1271（风光储多能互补系统优化设计中广泛采用）。

**2. 能源枢纽矩阵模型（方向2：能量转换与输入输出）**
能源枢纽是描述多能输入与多能输出转换关系的标准数学框架。

*   **2.1 经典能源枢纽矩阵**
定义输入向量 $P = [P_{wind}, P_{PV}, P_{tidal}]^T$，输出向量 $L = [L_{grid}, L_{H2}, L_{compute}, L_{marine}]^T$（分别代表外送电力、制氢、算力负荷、海洋用能）。
$$L = C \cdot \eta \cdot P$$
*参数说明*：$\eta$为设备转换效率矩阵；$C$为耦合分配矩阵。对于“蓝海枢纽”，由于包含海底算力这一柔性负荷，矩阵需引入算力调度因子。
*文献来源*：[图书/专著章节] DOI: 10.1002/9781394267392.ch1 (现代多向量能源枢纽 MV-EHs 理论)。

*   **2.2 氢能耦合与鲁棒约束**
制氢单元作为长时储能与价值转化中枢，其运行受限于电解槽的最小/最大负荷率及储罐容量约束。
$$P_{H2}(t) = \eta_{elec} \cdot P_{in}(t) - P_{fc}(t) / \eta_{fc}$$
$$V_{H2}(t) = V_{H2}(t-1) + P_{H2}(t)\Delta t - V_{ship}(t)$$
*参数说明*：$\eta_{elec}, \eta_{fc}$为电解与燃料电池效率；$V_{H2}$为储罐氢气体积；$V_{ship}$为船运外输量。
*文献来源*：[会议论文] DOI: 10.1109/PESIM67009.2026.11438300 (含氢综合能源枢纽鲁棒优化)。

$$\max F = \sum_{t=1}^{T} \left( \lambda_{grid}L_{grid}(t) + \lambda_{H2}V_{ship}(t) + \lambda_{comp}L_{compute}(t) - C_{opex}(t) - C_{penalty}(t) \right)$$
*参数说明*：$\lambda$为各形态产物的单位收益；$C_{opex}$为运维成本；$C_{penalty}$为弃风/弃光/弃潮惩罚。

#### 四、 海洋多能互补能源枢纽模型架构

1. **概率预测输入层** -> LSTM生成多源功率基准点预测 -> Copula函数生成预测误差联合分布带
2. **能源枢纽转换层** -> 构建输入向量[风,光,潮] -> 分配矩阵决定直送电网/制氢/算力比例 -> 输出向量[电,氢,算,用]
3. **多形态约束层** -> 氢气储罐质量平衡约束 -> 算力负荷柔性调节约束 -> 海缆外送功率波动率限制
4. **优化调度大脑** -> 日内以经济性最大化为目标 -> 实时以最小化预测误差惩罚为目标 -> 下发各端口控制指令

#### 五、 MATLAB/Simulink 仿真代码框架

以下为基于MATLAB的能源枢纽矩阵运算与优化调度底层代码框架：

```matlab
% =========================================================================
% 蓝海枢纽 - 海洋多能互补能源枢纽矩阵与调度模型框架
% 来源标注：基于丹麦能源岛及Dolphyn项目参数整合
% =========================================================================
clear; clc;

%% 1. 参数与矩阵初始化
% 时间步长设定
T = 24; dt = 1; % 24小时，1小时间隔
% 输入源：风、光、潮流 基准预测 (MW)
P_wind = 15 + 5*rand(1, T);   % 漂浮式风电
P_pv = 5*(sin(linspace(0,pi,T)))' + 0.5*rand(1,T); P_pv(P_pv<0)=0; % 光伏
P_tidal = 1.5 + 0.5*sin(2*pi*(1:T)/12); % 潮流能

% 效率参数 [来源: 英国Dolphyn创新报告及假设]
eta_trans = 0.97; % 升压并网效率
eta_elec = 0.65;  % 电解水制氢效率 (电->氢能)
eta_fc = 0.55;    % 燃料电池效率 (氢能->电)
PUE_compute = 1.08; % 算力PUE

% 能源枢纽分配系数矩阵 C (3x4) [需查证文献支撑，此处为策略演示]
% 列对应输入: [风,光,潮]，行对应输出流向: [直送电网, 制氢, 算力, 海洋用能]
% 约束: 每列相加 <= 1
C = [0.70, 0.80, 0.80;  % 直送电网比例
     0.15, 0.10, 0.10;  % 制氢比例
     0.10, 0.05, 0.05;  % 算力比例
     0.05, 0.05, 0.05]; % 海洋用能比例

%% 2. 动态调度与矩阵运算
P_in = [P_wind; P_pv; P_tidal]; % 3xT 输入矩阵
L_out = zeros(4, T);            % 4xT 输出矩阵
V_H2_tank = zeros(1, T);        % 储氢罐状态
V_H2_tank(1) = 50;              % 初始氢气储量

for t = 1:T
    % [模块A] 能源枢纽转换 [来源: DOI: 10.1002/9781394267392.ch1]
    P_alloc = C * P_in(:, t); % 当前各端口分配到的功率
    
    % 1. 直送电网 (考虑升压损耗)
    L_out(1, t) = P_alloc(1) * eta_trans;
    
    % 2. 制氢转化 (考虑电解效率) -> 转化为氢气质量流量
    P_H2_in = P_alloc(2); 
    % 1 MW * 1h = 3600 MJ, 氢热值120 MJ/kg -> 效率0.65 -> 约19.5 kg/MWh
    m_H2_prod = P_H2_in * 19.5; 
    
    % 3. 算力负荷 (作为柔性负荷，假设按分配功率定载运行)
    L_out(3, t) = P_alloc(3) / PUE_compute; % 实际算力有效负荷
    
    % 4. 海洋用能 (直供)
    L_out(4, t) = P_alloc(4);
    
    % [模块B] 储氢与船运外输约束 [来源: DOI: 10.1109/PESIM67009.2026.11438300]
    if t > 1
        % 假设每8小时有船运运走100kg氢气
        m_H2_ship = 100 * (mod(t, 8) == 0);
        % 储罐质量平衡
        V_H2_tank(t) = V_H2_tank(t-1) + m_H2_prod - m_H2_ship;
    else
        V_H2_tank(t) = V_H2_tank(t) + m_H2_prod;
    end
    
    % 储罐容量约束 (0 ~ 500 kg)
    if V_H2_tank(t) > 500
        V_H2_tank(t) = 500; % 满载弃氢
    elseif V_H2_tank(t) < 0
        % 触发燃料电池放电补足
        deficit = -V_H2_tank(t);
        L_out(1, t) = L_out(1, t) + deficit * 120 / 3600 * eta_fc; % 氢转电
        V_H2_tank(t) = 0;
    end
end

%% 3. 经济性评价 [来源: 期刊论文 TM61 节能.2026(06)]
% 假设参数 [假设值，待企业调研校准]
lambda_grid = 400;    % 元/MWh (上网电价)
lambda_H2 = 30;       % 元/kg (绿氢售价)
lambda_comp = 600;    % 元/MWh (算力服务费)
C_opex = 50;          % 元/MWh (综合运维成本)

% 综合收益计算
Revenue_grid = sum(L_out(1,:)) * lambda_grid;
Revenue_H2 = sum(V_H2_tank > 0) * lambda_H2; % 简化计算，实际按外输累计
Revenue_comp = sum(L_out(3,:)) * lambda_comp;
Cost_opex = sum(P_in(:)) * C_opex;

Total_Profit = Revenue_grid + Revenue_H2 + Revenue_comp - Cost_opex;
fprintf('当前策略下蓝海枢纽24小时综合收益预估为: %.2f 元\n', Total_Profit);

%% 4. 结果可视化
figure;
subplot(2,1,1);
bar(1:T, [P_wind', P_pv', P_tidal'], 'stacked'); 
title('多源输入功率曲线 (风/光/潮)'); legend('风电','光伏','潮流能'); ylabel('功率;
subplot(2,1,2);
plot(1:T, L_out(1,:), '-o', 1:T, V_H2_tank, '-s');
title('枢纽输出与储氢状态'); legend('并网功率(MW)', '储氢罐余量'); ylabel('功率/质量');
```

### 五、海洋新能源集群设计

#### 一、 核心文献提取与数学基础构建

**1. 混合海洋可再生能源空间协同（方向2：空间共享与多源平滑）**

*   **1.1 同场利用空间折减系数**
在同一海域布置风-光-潮设备，存在海洋空间重叠与尾流/遮挡相互影响。需引入同场利用折减系数。
$$P_{cluster\_raw} = \sum_{i=1}^{N} P_i \cdot (1 - \delta_{space, i})$$
*参数说明*：$P_i$为单场场站理论出力；$\delta_{space, i}$为空间折减系数（如光伏布置在风机间距内，受风机尾流湍流影响导致发电损失，通常取3%~8%）。
*文献来源*：[期刊论文] 中国工程科学 . 2026, 28(03) : 40-53《中国海上多场景综合能源岛发展研究》

*   **1.2 多能时空平滑与变异系数**
风、光、潮流因物理机制不同，其出力峰值在日内存在错位效应。平滑效应可通过集群出力变异系数 $CV$ 量化：
$$CV = \frac{\sigma(P_{wind} + P_{PV} + P_{tidal})}{\mu(P_{wind} + P_{PV} + P_{tidal})}$$
*文献来源*：[会议论文] DOI: 10.23919/AEIT63317.2024.10736733（评估混合系统典型气象年的互补特性，证明多源叠加显著降低CV）。

**2. Offshore Energy Hub 物理送出与网络架构（方向1：海缆与氢送出竞争）**

*   **2.1 海缆传输损耗与热约束模型**
多能汇集至中枢母线后升压送出，交流海缆存在电阻损耗，且受热容限约束。
$$P_{loss}(t) = I_{cable}^2(t) \cdot R_{cable}(L) = \frac{P_{send}^2(t)}{V^2 \cos^2\varphi} \cdot r_0 \cdot L$$
$$P_{send}(t) \le S_{cable\_max} \cdot V \cdot \cos\varphi$$
*参数说明*：$R_{cable}$为海缆总电阻；$r_0$为单位长度电阻；$L$为送电距离；$V$为送电电压；$\cos\varphi$为功率因数；$S_{cable\_max}$为海缆热容量限额。
*文献来源*：[期刊论文] 电力系统自动化 . 2020, 44(24) : 60-67《基于物质-能量流解析的海上微综合能源系统风险评估》

*   **2.2 电送 vs 氢送（管道/船运）经济性边界模型**
深远海（>100km）场景下，海缆成本呈非线性急剧上升，需建立“电氢送出临界距离”判据：
$$C_{cable}(L) = c_1 \cdot L + c_2 \cdot P_{max}$$
$$C_{H2}(L) = c_3 \cdot P_{electrolyzer} + c_4 \cdot L_{pipe} \text{ (或 } c_5 \cdot V_{ship}\text{)}$$
*判据*：当 $C_{cable} > C_{H2}$ 时，集群转为就地制氢送出。
*文献来源*：[期刊论文] DOI: 10.13335/j.1000-3673.pst.2023.1726（含海上风电制氢的综合能源系统分布鲁棒优化运行，探讨送出方式边界）。

*   **2.3 物质-能量流拓扑矩阵**
定义集群网络节点-支路关联矩阵 $A$，描述能量路由：
$$A \cdot \mathbf{F} + \mathbf{L} = \mathbf{P}$$
*参数说明*：$A$为节点关联矩阵（包含拓扑结构）；$\mathbf{F}$为支路传输流向量（海缆功率/氢管流量）；$\mathbf{L}$为节点负荷向量；$\mathbf{P}$为节点注入功率向量。
*文献来源*：[期刊论文] 电力系统自动化 . 2020, 44(24) : 60-67

#### 三、 完整模型补充：集群网络拓扑优化逻辑

构建完整的集群设计，还需引入**网络拓扑寻优**（如何将风机、光伏、潮流机组用海缆连接至中枢升压站/制氢平台，使总投资最小）。

**1. 最小生成树（MST）拓扑寻优模型**
设节点集合 $V$（包含各发电装备与枢纽节点），边集合 $E$（可能的海缆路径），寻找一棵生成树 $T$ 使建设成本最小：
$$\min \sum_{(i,j) \in T} \left( C_{fix}(i,j) + C_{var}(i,j) \cdot P_{rated}(i,j) \right)$$
$$\text{s.t.} \quad \sum P_{node} \le P_{cable\_limit}$$
*文献来源*：通用海上风电场内部集电系统优化设计理论延展 [需查证文献支撑]。

#### 四、 海洋能源集群设计架构

1. **资源与空间布局层** -> 确定风/光/潮场站位置 -> 计算同场利用折减系数 $\delta_{space}$ -> 生成集群原始总功率
2. **多源平滑效应层** -> 多能功率叠加 -> 计算变异系数CV -> 确定合理的集群外送容量（避免按单源峰值叠加导致海缆浪费）
3. **物理网络寻优层** -> 基于MST算法规划内部集电海缆拓扑 -> 选定中枢能源枢纽节点
4. **送出方式决策层** -> 计算临界距离 $L_{crit}$ -> 若 $L < L_{crit}$ 则海缆送电，否则就地制氢/船运或管输

#### 五、 MATLAB/Simulink 仿真代码框架

以下代码展示了海洋能源集群的空间平滑计算、海缆损耗以及送出方式的经济性临界判据：

```matlab
% =========================================================================
% 蓝海枢纽 - 海洋能源集群空间协同与物理送出模型框架
% 来源标注：基于PosHYdon项目参数与中国工程科学文献整合
% =========================================================================
clear; clc;

%% 1. 集群参数与环境初始化
% 模拟三个子场站：漂浮风电、光伏、潮流
t_end = 24; dt = 1; t = 1:t_end;
P_wind = 10 + 5*sin(2*pi*t/24);    % MW
P_pv = 8*(sin(pi*(t-6)/12)).^2; P_pv(P_pv<0)=0; % MW
P_tidal = 3 + 2*sin(2*pi*t/12);    % MW

% 空间共享折减系数 [来源: 中国工程科学. 2026]
delta_wind = 0.00; % 风电作为主导，无折减
delta_pv = 0.05;   % 光伏受风机尾流影响折减5%
delta_tidal = 0.03;% 潮流受平台桩基尾流影响折减3%

% 计算折减后集群总功率
P_cluster = P_wind*(1-delta_wind) + P_pv*(1-delta_pv) + P_tidal*(1-delta_tidal);

% 多源平滑效应评估 [来源: DOI: 10.23919/AEIT63317.2024.10736733]
CV_single = std(P_wind) / mean(P_wind); % 单一风能变异系数
CV_multi = std(P_cluster) / mean(P_cluster);
fprintf('单一风电变异系数: %.3f, 多能集群变异系数: %.3f\n', CV_single, CV_multi);

V_grid = 220; % kV
cos_phi = 0.95;
r0 = 0.05; % Ohm/km
S_cable_max = 250; % MVA 热容量限值
P_send_max = S_cable_max * cos_phi; % MW

L_array = 0:10:150;

c3_H2 = 10;     % 百万元/MW (电解槽固定投资分摊)

% 集群最大外送需求

    L = L_array(i);
    
    % 计算海缆损耗 [来源: 电力系统自动化. 2020]
    P_loss = (P_cluster_max * 1e6)^2 * (r0 * L) / ((V_grid * 1e3)^2 * cos_phi^2) / 1e6; % MW

    if (P_cluster_max + P_loss) > P_send_max
        Cost_cable(i) = inf; % 超过海缆热容量，物理不可行

        Cost_cable(i) = c1_cable * L + c2_cable * P_cluster_max;
    end
    
    % 制氢送出成本计算 [来源: DOI: 10.13335/...pst.2023.1726]
    Cost_H2(i) = c3_H2 * P_cluster_max + c4_H2_pipe * L;
end

% 寻找经济性临界距离
idx_cross = find(Cost_H2 < Cost_cable, 1);
if ~isempty(idx_cross)
    fprintf('电-氢送出经济性临界距离约为: %d km\n', L_array(idx_cross));
end

%% 3. 结果可视化

title('海洋多能集群空间平滑叠加效应'); legend('风电','光伏','潮流','集群总功率');

subplot(2,1,2);
```

### 海洋能源岛源侧模型

#### 一、 核心理论与数学基础构建

**1. 海洋环境多变量时间序列模型**
海洋环境要素并非独立存在，风-浪-流之间存在强物理耦合。需建立联合环境模型以生成符合真实海况的时间序列。

*   **1.1 风速与波浪耦合模型**
风速与有效波高（$H_s$）及谱峰周期（$T_p$）存在非线性正相关。基于JONSWAP谱经验公式与长期观测数据拟合：
$$H_s = a \cdot v_{10}^b + \epsilon_{wave}, \quad T_p = c \cdot H_s^{0.5}$$
*参数说明*：$v_{10}$为海平面10m处风速；$a, b, c$为经验系数（北海典型取值 $a=0.21, b=2.19, c=3.3$ [需查证文献支撑]）；$\epsilon_{wave}$为波浪随机扰动。
*文献来源*：[会议论文] DOI: 10.23919/AEIT63317.2024.10736733（混合系统典型气象年评估中风浪联合分布模型）。

*   **1.2 太阳辐照随机遮挡模型**
海上云层移动导致辐照呈阶跃性波动。采用马尔可夫链-蒙特卡洛（MCMC）方法生成晴空指数 $k_t$ 时间序列：
$$k_t(t+1) = f_{trans}(k_t(t), P_{ij})$$
$$G(t) = k_t(t) \cdot G_{clearsky}(t)$$
*参数说明*：$P_{ij}$为云层状态转移概率矩阵；$G_{clearsky}$为天文晴空辐照度。
*文献来源*：[期刊论文] DOI: 10.16085/j.issn.1000-6613.2023-1271（多能系统优化设计中光资源建模）。

**2. 能源岛源侧高级约束模型**

*   **2.1 预测误差耦合模型**
多源预测误差在时间尺度上具有发散性（超前时间越长，误差越大）。采用带有趋势项的随机游走模型描述超前 $k$ 步的误差带：
$$e_i(t+k) = e_i(t) + \sum_{j=1}^{k} \mathcal{N}(0, \sigma_{i,j}^2)$$
*参数说明*：$\sigma_{i,j}$为第 $i$ 种能源在 $j$ 步超前预测的误差标准差。风光的 $\sigma$ 随 $k$ 急剧增大，而潮流能因潮汐天文规律可精确预报，其 $\sigma$ 极小。
*文献来源*：[期刊论文] DOI: 10.13335/j.1000-3673.pst.2023.1726（含海上风电制氢系统分布鲁棒优化，处理不确定性）。

*   **2.2 强迫停运与可靠性权重模型**
源侧设备受海洋高盐雾腐蚀影响，故障率高于陆地。引入强迫停运率（FOR）及可靠性权重系数 $\omega_i$：
$$\omega_i = 1 - FOR_i$$
$$P_{source\_actual}(t) = \sum_{i=1}^{N} \omega_i \cdot S_i(t) \cdot P_{i\_forecast}(t)$$
*参数说明*：$FOR_i$为机组强迫停运率（海上风电通常取3%~5%，海流机取5%~8% [需查证文献支撑]）；$S_i(t) \in \{0,1\}$为基于马尔可夫状态转移的设备运行/故障状态。
*文献来源*：[期刊论文] 电力系统自动化 . 2020, 44(24) : 60-67（基于物质-能量流解析的海上微综合能源系统风险评估）。

*   **2.3 极端天气生存约束（Cut-off & Survival）**
当遭遇台风等极端海况时，机组需执行保护性切出。定义环境生存约束逻辑：
$$\text{if } v_{hub} > v_{cut\_out} \text{ or } H_s > H_{survival} \Rightarrow P_{source} = 0$$
*参数说明*：$v_{cut\_out}$为切出风速（约25m/s）；$H_{survival}$为平台生存极限波高（漂浮式通常取10m~15m）。
*文献来源*：[学位论文] DOI: 10.27140/d.cnki.ghbbu.2024.002290（大型海上漂浮式风电机组响应分析与稳定性控制研究）。

#### 三、 完整海洋源侧模型体系架构（面向仿真验证对接）

1. **环境数据驱动层** -> 输入：天文潮汐预报、气象预报初值 -> 生成风-浪-流-光耦合的8760小时/秒级时间序列
2. **单源物理映射层** -> 将环境序列输入前序建立的各机组物理模型 -> 输出各单源理论机械/电气功率
3. **极端工况裁决层** -> 实时扫描风速与波高 -> 触发生存约束逻辑 -> 越限时强制功率清零
4. **可靠性与误差叠加层** -> 基于FOR生成设备随机停机状态 $S_i(t)$ -> 叠加多时间尺度预测误差 $e_i(t)$ -> 生成预测功率带 $[P_{min}, P_{max}]$ 与实际可用功率
5. **能源岛集群汇聚层** -> 可靠性加权求和 -> 空间平滑效应折减 -> 输出面向调度的“源侧可用总功率序列”及“预测误差分布”

#### 四、 MATLAB/Simulink 仿真代码框架

以下代码展示了从环境数据生成到极端约束、预测误差及可靠性叠加的源侧全景验证模型：

```matlab
% =========================================================================
% 蓝海枢纽 - 海洋源侧模型体系全景仿真框架 (面向调度验证对接)
% 来源标注：基于WFA项目参数及多能不确定性文献整合
% =========================================================================
clear; clc;

%% 1. 环境时间序列生成 (以1天, 1小时间隔为例)
T = 24; t = 1:T;
% 基础气象输入
v_wind_base = 8 + 6*sin(2*pi*t/24) + 2*randn(1,T); % 基础风速
% [模块A] 风-浪耦合模型 [来源: DOI: 10.23919/AEIT63317.2024.10736733]
H_s = 0.21 * v_wind_base.^2.19 + 0.5*randn(1,T); H_s(H_s<0)=0.5;
% 光照 (白天存在，叠加云层随机遮挡)
G_clear = 1000 * max(0, sin(pi*(t-6)/12));
kt = 0.6 + 0.3*rand(1,T); % 晴空指数随机化
G_hor = G_clear .* kt;
% 潮流 (准确的天文预报)
v_tide = 2.5 + 1.0*sin(2*pi*t/12.4);

%% 2. 单源物理出力计算 (调用前序简化模型)
P_wind = min(16, 0.5 * 1.225 * pi * 65^2 * v_wind_base.^3 * 0.4 / 1e6); % 简化16MW风机
P_pv = 1.0 * (G_hor/1000) * 0.95; % 简化1MW光伏
P_tidal = min(1.5, 0.5 * 1025 * pi * 8.5^2 * v_tide.^3 * 0.42 / 1e6); % 简化1.5MW潮流

%% 3. 极端天气与生存约束层 [来源: DOI: 10.27140/d.cnki.ghbbu.2024.002290]
v_cut_out = 25; H_survival = 14;
for i = 1:T
    if v_wind_base(i) > v_cut_out || H_s(i) > H_survival
        P_wind(i) = 0; % 触发保护性切出
        P_pv(i) = 0;
        P_tidal(i) = 0; % 极端海况下潮流机也保护停机
    end
end

%% 4. 可靠性权重与停机模拟 [来源: 电力系统自动化. 2020]
FOR_wind = 0.042; FOR_pv = 0.02; FOR_tidal = 0.06; % 强迫停运率 [WFA项目参考]
S_wind = rand(1,T) > FOR_wind;
S_pv = rand(1,T) > FOR_pv;
S_tidal = rand(1,T) > FOR_tidal;
P_actual = P_wind.*S_wind + P_pv.*S_pv + P_tidal.*S_tidal;

%% 5. 预测误差叠加层 (超前1小时预测) [来源: DOI: 10.13335/j.1000-3673.pst.2023.1726]
% 风光误差大，潮流误差极小
err_wind = 0.15 * P_wind .* randn(1,T); 
err_pv = 0.20 * P_pv .* randn(1,T);
err_tidal = 0.03 * P_tidal .* randn(1,T);
P_forecast = P_actual + err_wind + err_pv + err_tidal;
P_forecast(P_forecast<0) = 0;

%% 6. 集群平滑汇聚层 [来源: 中国工程科学. 2026]
gamma_smooth = 0.92; % 多源空间平滑系数
P_hub_actual = sum(P_actual) * gamma_smooth;
P_hub_forecast = sum(P_forecast) * gamma_smooth;

%% 7. 结果可视化
figure;
subplot(2,1,1);
plot(t, v_wind_base, 'b', t, H_s, '--r'); yyaxis right;
title('环境输入: 风速与有效波高'); legend('风速', '波高 H_s'); xlabel('时间;
subplot(2,1,2);
hold on; area(t, P_wind, 'FaceColor', [0.6 0.8 1.0]);
area(t, P_pv, 'FaceColor', [1.0 0.8 0.6], 'BaseValue', 0); 
area(t, P_tidal, 'FaceColor', [0.8 1.0 0.8], 'BaseValue', 0);
plot(t, P_hub_actual, 'k-', 'LineWidth', 2);
plot(t, P_hub_forecast, 'r--', 'LineWidth', 1.5);
title('源侧可用功率与预测功率带 (含极端约束与停机)'); 
legend('风电实际','光伏实际','潮流实际','枢纽总实际','枢纽总预测');
ylabel('功率; xlabel('时间');
```
