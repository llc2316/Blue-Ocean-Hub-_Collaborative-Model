# 蓝海枢纽：漂浮式风电子模型 V2.0

> 本次角色：优化建模师（兼资料检索员）  
> 版本日期：2026-07-14  
> 适用范围：深远海能源岛“源”侧的单机、场级与调度接口模型  
> 原则：公开参考机组用于复现实验；国产商用机组只使用厂家或认证机构公开数据。未取得的数据不得反推为“厂家真实参数”。

## 1. 结论

现有 V1 框架覆盖了风速、气动、平台、传动、控制和场级聚合，但不能直接作为工程仿真模型。V2.0采用双层架构：

1. **高保真层（秒级载荷与稳定性）**：OpenFAST + AeroDyn + ElastoDyn/BeamDyn + HydroDyn + MoorDyn + ServoDyn/ROSCO，用于生成风—浪—流耦合响应、平台运动、功率波动与载荷样本。
2. **调度代理层（秒至小时、全年运行）**：MATLAB/Simulink采用经高保真或实测数据辨识的功率曲线/状态空间代理，输出可用功率、爬坡率、预测误差、停机状态和无功能力边界。

不能用一套 0.01 s 欧拉脚本同时承担载荷设计、控制器整定和 8760 h 经济调度。两个层级通过离线辨识与交叉验证连接。

## 2. 对V1的技术审计与修正

| V1内容 | 问题 | V2处理 |
|---|---|---|
| `Cp_max*(1-(lambda-lambda_opt)^2/100)*cos(beta)^2` | 人为经验面，可能出现负值，不能代表具体叶片 | 采用厂家/参考机组的二维 `Cp(lambda,beta)`、`Ct(lambda,beta)`表；无表时直接使用经验证的电功率曲线 |
| 转矩式使用 `C_T/lambda` | 推力系数 `C_T` 与转矩系数 `C_Q` 混用 | 使用 `T_a=0.5*rho*A*R*v_rel^2*C_Q`，且 `C_Q=C_P/lambda` |
| 频域 `A(omega),B(omega)`直接写入时域常微分方程 | 忽略辐射记忆效应 | 高保真层用 Cummins 方程或辐射状态空间实现 |
| Morison力只用水质点速度 | 未考虑构件相对速度、沿构件积分和适用尺度 | 由 HydroDyn 的势流/条带理论组合处理；降阶层只使用辨识后的平台模型 |
| `Delta Cp(pitch rate)`损失项 | 无可追溯标定关系 | 删除；动态入流、动态失速由 AeroDyn模型处理，代理误差单独辨识 |
| 直驱机套用任意双质量参数 | `Jr/Jg/Ks/Bs`均为假设，且与结构柔性重复计入风险高 | 调度层默认单等效惯量；研究轴系扭振时再启用有实参的双质量模型 |
| 变桨PI无独立积分状态，增益任意 | 数值维度和执行逻辑不成立 | 使用ROSCO整定结果或由线性化模型整定；加入限幅、速率限制和抗积分饱和 |
| 状态更新中位移/速度写反 | `X(1)`被定义为速度却用位移导数更新，`X(3)`反之 | 重新定义状态向量并由标准求解器积分 |
| `P_out=X(5).*X(6)*0.95` | 两个角速度相乘不是功率 | 电功率应由 `P_e=T_g*omega_g` 或经验证的电功率曲线给出 |
| 固定 `gamma_smooth`乘总功率 | 空间平滑不是能量损失系数，会错误降低电量 | 删除；逐机风场与尾流产生平滑，场功率直接逐机求和后扣除明确损耗 |
| 固定尾流折减率 | 忽略风向、间距、稳定度和控制 | 规划级用工程尾流模型；动态场级用 FAST.Farm 或经实测校准的尾流代理 |
| 风速超过阈值立即清零/恢复 | 缺少切出滞回、重启等待、降额与故障状态 | 使用运行状态机：正常—降额—停机—等待重启—恢复 |
| MySE 16 MW内部参数由“典型值”补齐 | 不能代表厂家真实模型 | 国产机型仅保留已公开额定功率/尺寸等；内部参数列入企业数据需求清单 |

## 3. 模型边界和时间尺度

| 层级 | 时间步长建议 | 主要输出 | 推荐工具 |
|---|---:|---|---|
| 气弹—水动高保真 | 0.005–0.025 s（最终按收敛性确定） | 6-DOF、转速、桨距、功率、推力、关键载荷 | OpenFAST/ROSCO |
| 电气暂态/短期稳定 | 毫秒至数十毫秒 | P/Q、电压电流、故障穿越、控制响应 | Simulink/Simscape Electrical或电力系统软件 |

时间步长为建模建议，不是设备参数；最终必须通过数值收敛试验确定。

## 4. 数学模型

### 4.1 环境输入

高保真层至少输入：三维湍流风场、有效波高、谱峰周期、波向、海流剖面、水位以及空气/海水密度。仅用正弦风和正弦波不能代表设计海况。

轮毂高度平均风速可由测量高度换算：
$U(z)=U(z_{ref})\left(\frac{z}{z_{ref}}\right)^\alpha$

但 `alpha` 必须由场址观测、激光雷达或再分析资料拟合；不再预设“海上通用值”。湍流时序应采用标准定义的正常/极端风况或由 TurbSim 生成，波浪采用场址联合分布和方向谱。

### 4.2 相对入流与气动功率

平台运动通过完整刚体运动学改变轮毂与叶素相对来流。简化到顺风向小角度时：
$U_{rel,h}\approx U_h-\dot{x}_{surge}-z_h\dot{\theta}_{pitch}$

该式只用于调度代理或小角度校验；高保真层使用坐标变换后的叶素局部相对速度。
$\lambda=\frac{\Omega R}{\max(U_{rel},\varepsilon)}$
$P_a=\frac12\rho_a A U_{rel}^{3}C_P(\lambda,\beta),\qquad T_a=\frac12\rho_a A R U_{rel}^{2}C_Q(\lambda,\beta)$

$C_Q=\frac{C_P}{\lambda},\qquad F_T=\frac12\rho_a A U_{rel}^{2}C_T(\lambda,\beta)$ 

其中 `Cp/Cq/Ct`必须来自公开参考模型、厂家认证曲线、BEM计算或试验辨识。调度级优先使用按照 IEC 61400-12-1 测得或等效校正的**电功率曲线**，避免重复叠加发电机效率。

### 4.3 浮式平台时域水动力

采用 Cummins 形式：
$[M+A_\infty]\ddot{q}(t)+\int_0^t K_r(t-\tau)\dot q(\tau)d\tau+C_hq(t)=F_{exc}+F_{visc}+F_{moor}+F_{aero}+F_{current}$

`q`为六自由度广义位移，`A_inf`为无限频率附加质量，`K_r`为辐射脉冲响应核。工程实现可将辐射卷积拟合为状态空间：

$\dot x_r=A_rx_r+B_r\dot q,\qquad F_{rad}=C_rx_r+D_r\dot q$

系泊力使用 MoorDyn 集中质量模型或经静态/动态试验校准的非线性恢复面。只有在工作点附近且误差验证合格时，才可写成：
$F_{moor}\approx F_{moor,0}-K_{moor}\Delta q-C_{moor}\Delta\dot q$

### 4.4 传动与机电转换

公开基线 IEA 15 MW 为直驱永磁同步发电机。调度级可用单等效惯量：

$J_{eq}\dot\Omega=T_a-T_g-B_{eq}\Omega$

若研究轴系扭振且取得真实参数，则使用一致坐标系的双质量模型：

$J_r\dot\Omega_r=T_a-K_s\delta-B_s(\Omega_r-\Omega_g)$
$J_g\dot\Omega_g=K_s\delta+B_s(\Omega_r-\Omega_g)-T_g$

$\dot\delta=\Omega_r-\Omega_g$

直驱情况下传动比为1。若改用齿轮箱机组，必须统一折算到高速轴或低速轴，不能混用。

### 4.5 控制器

额定风速以下的最优转矩控制可写为：

$T_{g,ref}=K_{opt}\Omega_g^2,\qquad K_{opt}=\frac12\rho_a A R^3\frac{C_{P,max}}{\lambda_{opt}^3}$ 

该表达式对应直接驱动、忽略损耗且变量位于同一轴侧。工程控制需包括区域1.5/2/2.5、最小转速、最大转矩和转矩速率限制。

额定以上由集体变桨调节转速/功率。控制器必须含滤波、增益调度、抗积分饱和、桨距幅值与速率约束。浮式机组需检查负阻尼问题，可采用ROSCO浮式反馈/陷波/峰值推力削减功能，参数由线性化模型或公开控制器文件获得，不在本文给出假增益。

### 4.6 电气接口

源储系统稳定分析至少输出机端或场站并网点的：


$0\le P_e\le \min(P_{avail},P_{conv,rated}),\qquad P_e^2+Q_e^2\le S_{conv}^2$

并加入有功爬坡、无功/电压控制、限流、故障穿越和辅助功率。短期电力系统稳定模型采用 IEC 61400-27-1:2020 的通用正序模型或厂家验证模型；电能质量与频率/惯量控制测试参考 IEC 61400-21-1:2019。

本项目默认“风机全功率变流器主要执行功率跟踪，构网型混合储能形成海上交流母线”作为待验证架构。若风机本体承担构网功能，需要厂家控制权限与专门的GFM模型，不能仅修改外环PI得到。

### 4.7 运行状态机与可用功率

单机不采用简单瞬时切出，而采用：


$s_t\in\{\text{normal, derated, stopped, restart-wait, fault}\}$

$P_{avail,t}=a_t\,d_t\,P_{curve}(U_{eq,t},\rho_t)$


`a_t`为可利用状态，`d_t`为调度/环境降额系数。切出、重启阈值、滞回时间、台风模式和允许海况必须来自厂家控制说明或认证文件；没有资料时均标记为 **[假设值，待企业调研校准]**。

### 4.8 风电场聚合


$P_{farm}(t)=\sum_{i=1}^{N}P_{e,i}(t)-P_{array\ loss}(t)-P_{aux}(t)$

逐机等效风速由环境风场、地形/海气稳定度、风向和尾流模型得到。空间平滑是逐机不同相风速叠加后的统计结果，不再乘固定 `gamma_smooth`。规划阶段至少计算：阵列效率、集电损耗、可利用率、限电、爬坡率、功率谱密度和不同时间窗的变异系数。

### 4.9 调度接口

漂浮式风电子模型向“储—算—用”联合优化提供：

- `P_avail(t)`：可用有功功率；
- `P_min/P_max(t)`：预测区间或场景集；
- `dP_up/dP_down`：爬坡边界；
- `Q_min/Q_max(t)`：无功能力；
- `state(t)`：正常、降额、停机、故障、重启等待；
- `reserve_headroom(t)`：可用于降载调频的上调裕度；
- `quality_flag(t)`：输入数据与代理模型适用性标志。

预测模型、故障模型与物理模型分层实现，避免将预测误差重复叠加到“实际功率”。

## 5. 可复现基线与国产化映射

### 5.1 公开参考基线

建议以 **IEA Wind 15-MW Reference Wind Turbine + UMaine VolturnUS-S半潜式平台** 作为第一阶段可复现基线。公开资料给出15 MW额定功率、240 m叶轮直径、直驱永磁同步发电机、控制器和OpenFAST输入文件；转子设计目标 `Cp≈0.489`。这些参数来源于NREL/IEA公开参考模型，**不是商业设备参数**。

### 5.2 国产商用机型映射原则

国产设备选型确定后，至少向厂家/认证机构索取下列数据：

1. 空气密度修正后的电功率曲线、推力曲线及不确定度；
2. `Cp/Ct/Cq(lambda,beta)`表或等价气动模型；
3. 转子、发电机、塔架、平台质量/惯量和模态参数；
4. 平台水动力数据库（附加质量、辐射阻尼、激振力/QTF）与系泊参数；
5. 控制器版本、转矩/桨距限值、切出重启状态机和台风策略；
6. 变流器额定容量、损耗图、P-Q能力、限流、故障穿越及通用模型参数；
7. SCADA采样定义、可利用率、故障码、辅助功率和运维停机数据。

在上述资料缺失时，可用公开参考机组做算法验证，但不得把结果冠以具体国产型号。

## 6. MATLAB/Simulink迭代方案

项目目录中的 `floating_wind_dispatch_v2.m` 是调度级单机/多机代理，包含：

- 经验证电功率曲线插值；
- 小角度平台运动相对风速修正（可关闭）；
- 切出滞回与重启等待状态机；
- 可利用率、降额、辅助功率与场内损耗；
- 有功爬坡限制和 P-Q 能力边界；
- 逐机求和，不使用固定平滑折减系数。

`demo_floating_wind_dispatch_v2.m` 只用于代码冒烟测试。其风速、平台运动和功率曲线为 **[示例值，不得用于项目结论]**。

建议的Simulink总线：

```text
EnvironmentalBus -> TurbineSurrogate -> OperatingStateMachine
                 -> ActivePowerLimiter -> ConverterPQ -> FarmAggregator
OpenFAST outputs -> Identification/Validation -------------------^
```

## 7. 校准与验证计划

1. **单点校验**：切入、额定、切出附近功率连续性及限值。
2. **功率曲线校验**：对公开参考模型或厂家曲线计算RMSE、MAE、能量偏差。
3. **动态校验**：用OpenFAST在多个平均风速、波况、风浪夹角和随机种子下生成样本，比较功率PSD、平台纵摇PSD、转速与桨距响应。
4. **状态机校验**：切出滞回、重启等待、故障和降额场景。
5. **场级校验**：不同风向与间距下阵列效率、爬坡率和空间平滑统计量。
6. **电气校验**：功率阶跃、无功阶跃、低/高电压穿越、限流和频率响应。
7. **跨层校验**：调度代理在训练域与外推域分别报告误差；外推时设置 `quality_flag=0`。

验收阈值不得凭空设定，应由项目仿真精度目标、标准测试要求和企业数据质量共同确定。
