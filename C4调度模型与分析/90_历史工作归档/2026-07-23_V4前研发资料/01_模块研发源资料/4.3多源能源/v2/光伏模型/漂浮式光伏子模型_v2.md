# 蓝海枢纽：漂浮式光伏子模型 V2.0

> 本次角色：优化建模师（兼资料检索员、仿真分析员）  
> 版本日期：2026-07-14  
> 适用范围：近岸至深远海漂浮式光伏的发电性能、环境修正、运行约束及源侧调度接口  
> 原则：公式使用标准或可追溯文献；项目通报数据只代表相应项目，不外推为通用参数。

## 1. V2.0结论

V1已经覆盖辐照、温度、平台运动、腐蚀和逆变器，但其经验系数不足以支撑工程结论。V2采用三层架构：

1. **结构—水动力层**：输出各浮体/子阵列的升沉、横摇、纵摇、偏航、连接件载荷、系泊张力和动态海缆边界。
2. **光伏电气性能层**：根据太阳矢量、动态组件法向量、平面辐照、组件温度、I-V/IEC 61853性能、MPPT拓扑和逆变器效率计算AC功率。
3. **调度代理层**：向源储算用优化提供可用功率、预测区间、爬坡率、无功能力、停运状态和数据质量标志。

水库/港池、近岸全海水和开敞深海不是同一种设计工况。青岛炼化项目可用于近岸全海水运行与冷却研究；山东半岛南3号、中集半潜式平台和北海示范项目更适合用于深远海结构—发电耦合研究。

## 2. V1技术审计

| V1内容 | 问题 | V2处理 |
|---|---|---|
| 水平面辐照 `G_hor`直接进入组件功率 | 未进行DNI/DHI/GHI分解、太阳位置和倾斜面换算 | 使用太阳单位矢量与动态组件法向量计算直射、天空散射和海面反射分量 |
| `theta_inc=0` | 只代表理想正入射瞬间 | 按时间、位置、组件方位/倾角和平台6-DOF逐时计算入射角 |
| `cos(theta_inc+theta_platform)/cos(theta_inc)` | 接近掠射时可能发散，也不能表示三维横摇/纵摇/偏航 | 使用三维旋转矩阵和点积 `max(0,s·n)` |
| 波高超过2 m后线性遮挡 | 阈值和斜率无实验依据 | 遮挡由几何模型/试验或实测辨识；没有数据时作为独立输入，不写死经验式 |
| `Tcell=Tair+ksea*G` | 忽略风速、结构通风、热容、水温和接触方式 | 架空式采用校准后的Faiman模型；水接触薄膜式采用瞬态能量平衡或实测温度 |
| 固定“海上温度系数” | 不同浮体结构的散热机理不同 | `U0/U1`或换热系数按具体结构、场址实测标定 |
| 盐雾导致固定指数年衰减 | IEC 61701是耐盐雾试验，不能直接生成年度能量衰减率 | 将盐沉积/污损、不可逆退化和故障可利用率拆分建模 |
| 固定逆变器效率0.98 | 忽略部分负载、输入电压、温度降额和削顶 | 使用厂家效率曲线或Sandia/CEC逆变器模型 |
| 组件数简单相乘 | 功率可相加，但没有校验组串电压、MPPT范围、短路电流和温度边界 | 增加组串—MPPT—逆变器拓扑及IEC 62548设计校验 |
| 只有统一波浪损失系数 | 实际包含平均姿态辐照损失与MPPT内失配损失 | 分别计算WIL的辐照分量和电气失配分量 |
| 盐雾、冷却、波浪系数直接连乘 | 容易重复计损或掩盖物理机理 | 各损失保留独立输出和可校准参数 |
| 无运行状态机 | 极端海况、绝缘故障、检修时仍可能输出功率 | 增加正常、降额、停机、等待重启和故障状态 |

## 3. 工程场景分级

| 场景 | 典型特征 | 模型重点 |
|---|---|---|
| 水库/封闭水域 | 小浪、低盐或淡水、易维护 | 温度、遮挡、锚固、水位变化 |
| 港池/近岸全海水 | 潮汐、盐雾、一定波流、可接近 | 腐蚀、绝缘、潮位、污损、运维 |
| 开敞海域/风光同场 | 长周期涌浪、强风、方向性波浪 | 水弹性、连接器、系泊、动态海缆、WIL |
| 深远海半潜式 | 高海况、远程运维、平台级结构 | 6-DOF、疲劳、生存工况、冗余和可维护性 |

DNV-RP-0584主要面向内陆和近岸遮蔽水域，对严酷离岸环境只能作为一般指南。深远海方案还需结合海工结构规范、NB/T 11744-2024、NB/T 11814-2025及项目专用设计基础。

## 4. 数学模型

### 4.1 太阳位置与动态组件法向量

在东—北—天（ENU）坐标系中，令太阳单位矢量为 `s(t)`，静态组件法向量为 `n0`。平台横摇、纵摇、偏航分别为 `phi, theta, psi`：

\[
$n(t)=R_z(\psi)R_y(\theta)R_x(\phi)n_0$
\]

\[
$\cos\theta_i(t)=\max[0,s(t)^Tn(t)]$
\]

对于柔性膜或多浮体阵列，应对每个刚性子阵列/MPPT分区分别计算 `n_j(t)`，不能只用整个平台平均倾角。

### 4.2 动态平面辐照度

规划级可先用各向同性散射模型：

\[
$G_{POA,f}=DNI\cos\theta_i+DHI\frac{1+n_z}{2}+\rho_{sea}GHI\frac{1-n_z}{2}$
\]

详细能量评估应使用经验证的Perez或Hay-Davies换算模型。海面反照率并非常数：它受太阳高度、风浪、天空状态和方向性镜面反射影响；没有场址测量时，`rho_sea`应标记为 **[假设值，待企业调研校准]**。

入射角修正：

\[
$G_{eff,f}=IAM(\theta_i)G_{beam}+G_{diffuse}+G_{reflected}$
\]

`IAM`应来自IEC 61853-2试验、组件厂家数据或经验证的玻璃模型。

双面组件可写为：

\[
$G_{eff}=G_{eff,f}+\varphi_{bi}G_{rear}$
\]

其中双面率 `varphi_bi`来自组件数据表；背面辐照需考虑浮体遮挡、离水高度、海面反射和邻排遮挡，不用固定“海上双面增益”。

### 4.3 组件温度

对背面通风的架空/半潜式组件，可用Faiman模型：

\[
$T_m=T_a+\frac{G_{eff}}{U_0+U_1WS}$
\]

`U0/U1`必须按目标结构实测标定。IEA PVPS报告指出，浮筒架空组件通常以空气对流散热，而直接铺设在薄膜并与水热接触的组件以水侧传热为主，两者不能共用一套系数。

水接触或热惯性不可忽略时，采用瞬态能量平衡：

\[
$C_{th}\frac{dT_m}{dt}=\alpha G_{POA}-\frac{P_{dc}}{A}-h_a(T_m-T_a)-h_w(T_m-T_w)-q_{rad}$
\]

`Cth, ha, hw, emissivity`均需试验或详细热模型校准。调度模型可直接输入实测/高保真模型得到的 `Tmodule(t)`。

### 4.4 组件与阵列DC模型

设备资料充分时，优先顺序为：

1. IEC 61853辐照—温度性能矩阵；
2. 厂家/实验室参数化单二极管模型；
3. 仅用于规划级的线性功率近似。

线性近似为：

\[
$P_{dc}=P_{STC}\frac{G_{eff}}{G_{STC}}[1+\gamma_P(T_m-T_{STC})]$
\]

该式不得用于旁路二极管动作、局部遮挡、低辐照I-V非线性或MPPT电压越界研究。

单二极管模型为：

\[
$I=I_{ph}-I_0\left[\exp\left(\frac{V+IR_s}{nN_{s}V_{T}}\right)-1\right]-\frac{V+IR_s}{R_{sh}}$
\]

模型参数来自厂家数据、IEC 61853测试或I-V实测辨识。

### 4.5 波致损失与MPPT失配

总波致损失分成：

\[
$WIL=WIL_{irradiance}+WIL_{mismatch}$
\]

- `WIL_irradiance`：动态平均姿态与静态参考姿态之间的辐照/能量差；
- `WIL_mismatch`：同一串或同一MPPT内组件姿态、遮挡和辐照不同造成的电气失配。

若同一刚性浮体上的组件姿态一致且配置独立MPPT，失配可显著小于“一组件一浮体且串联跨波峰”的方案。工程模型必须显式保存“组件—组串—MPPT—逆变器”的映射。

### 4.6 盐沉积、污损与长期退化

三者分开处理：

\[
$P_{dc,net}=P_{dc}\,f_{soil}(t)\,f_{bio}(t)\,f_{deg}(t)\,a(t)$
\]

- `fsoil`：玻璃盐沉积、鸟粪和气溶胶造成的可清洗损失；
- `fbio`：水下浮体/系泊生物污损间接导致的姿态、载荷和维护影响；
- `fdeg`：封装、背板、接线盒、连接器、PID等不可逆退化；
- `a(t)`：故障与维护可利用状态。

IEC 61701盐雾试验只能用于耐腐蚀资格评价，不能直接推出“每年衰减x%”。退化率必须由同类设备长期数据或加速试验—现场相关性给出。

### 4.7 逆变器与电气约束

\[
$P_{ac}=min[P_{dc,net}\eta_{inv}(P_{dc},V_{dc},T_{inv}),P_{ac,rated}]-P_{aux}-P_{cable}$
\]

\[
$P_{ac}^2+Q^2\le S_{inv}^2$
\]

还应校验组串开路电压、MPPT电压窗口、最大输入电流、温度降额、绝缘监测、直流电弧、接地故障、海缆载流量和无功控制。深远海动态电缆弯曲和连接可靠性属于结构—电气耦合边界。

### 4.8 运行状态机

\[
$s_t\in\{normal,derated,stopped,restart\mbox{-}wait,fault\}$
\]

触发因素至少包括：风速、有效波高/极端波、平台姿态、系泊或连接器告警、绝缘电阻、逆变器温度、海缆状态和人工检修。阈值、滞回及重启时间必须来自目标平台与设备资料，均为 **[假设值，待企业调研校准]**。

## 5. 项目实例及其可用数据边界

### 5.1 山东半岛南3号风光同场实证

- 500 kW深远海漂浮式光伏实证项目，与300 MW海上风电场同场；采用环形HDPE浮体、弹性薄膜、4个系泊点和12条缆索。【来源类型：国家发展改革委转载行业信息】
- 项目通报称水体冷却可提高效率10%以上。该数字只用于“存在冷却效应”的项目证据，不能作为其他平台的 `ksea` 或统一增益。
- 可用于核验：风光同场接口、膜式水接触热模型、系泊拓扑、动态辐照和运行数据需求。

### 5.2 中集半潜式海上光伏平台

- 400 kWp、约1900 m²净甲板，包含浮式结构、系泊、光伏/逆变、监测、动态海缆和消纳系统。【来源类型：国家能源局派出机构转载行业信息】
- 项目通报的6.5 m浪高、34 m/s风速、4.6 m潮差为该平台公开能力边界，不得直接作为其他设备停机/生存阈值。
- 可用于核验：半潜式多浮体阵列、平台级姿态输入、动态海缆与智能监测接口。

### 5.3 青岛炼化全海水环境项目

- 2025年投用，漂浮部分装机7.5 MW、占水面约60000 m²；项目通报称冷却增益5%–8%。【来源类型：国家能源局转载新华社】
- 其水域与海域联通，更适合作为近岸全海水运行、盐雾、潮汐和运维案例，不代表开敞深远海波浪工况。

### 5.4 国际开敞海域项目

- RWE/SolarDuck Merganser于2024年安装，重点验证结构、锚固、电气、制造安装和运维；公开信息显示使用180余个传感器监测结构载荷、连接/锚固载荷和电气性能。【来源类型：开发商项目资料】
- Oceans of Energy在荷兰Hollandse Kust Noord运行风光同场离岸光伏，公开资料称水深约25 m、约1500块组件。【来源类型：技术开发商项目资料】

开发商资料可证明工程路径和监测字段，但不能替代独立第三方能量、可靠性和寿命验证。

## 6. MATLAB/Simulink迭代

项目目录中的 `floating_pv_dispatch_v2.m` 实现调度级代理：

- 三维平台姿态与太阳矢量；
- 直射、天空散射和海面反射；
- 入射角修正、可选背面辐照；
- Faiman温度或外部组件温度输入；
- IEC 61853性能矩阵或线性规划级模型；
- MPPT子阵列聚合、污损/退化/失配独立因子；
- 逆变器部分负载效率、削顶、辅助功率和电缆损耗；
- 海况停机、重启等待、可控上升爬坡和P-Q能力。普通光伏逆变器不能阻止资源驱动的快速功率下降；下降波动原样传递给储能层。

每个输入列代表一个**独立MPPT子阵列**。如果多个姿态不同的组件串联到同一MPPT，必须增加单二极管/旁路二极管网络，当前调度代理不能计算该类细粒度失配。

`demo_floating_pv_dispatch_v2.m`中的辐照、姿态、海况和设备参数均为 **[示例值，不得用于项目结论]**。

建议Simulink接口：

```text
SolarResource + PlatformMotion -> DynamicPOA -> ThermalModel -> PV/DC Model
                                                     |             |
ElectricalTopology ----------------------------------+-> MPPT/Inv -> StateMachine
Hydro/Mooring alarms -------------------------------------------------^
```

## 7. 与源储算用调度的接口

输出至少包括：

- `P_available(t)`、`P_actual(t)`与预测区间；
- `P_dc(t)`、逆变器削顶和各类损失分解；
- `dP/dt`及可控降载裕度；
- `Qmin/Qmax(t)`；
- 平台/电气运行状态和停机原因；
- `Tmodule`、`POA`、姿态、绝缘/故障等质量标志；
- WIL辐照分量与WIL失配分量。

光伏逆变器可提供无功和有功限幅，但若其承担构网功能，需要厂家GFM模型、直流侧储能或足够的可控功率裕度；不能从普通MPPT模型直接推导出黑启动能力。

## 8. 校准与验证计划

1. **辐照链校验**：固定姿态下与SAM/pvlib及倾斜面传感器对比。
2. **姿态校验**：刚体旋转方向、太阳矢量、极端角度和夜间输出测试。
3. **温度校验**：按平台类型分别拟合 `U0/U1`或瞬态热参数，报告RMSE和偏差。
4. **电气校验**：IEC 61853矩阵、实测I-V、MPPT范围、逆变器效率和削顶。
5. **水池/海试校验**：同步测量波浪、6-DOF、逐MPPT辐照、电流、电压和AC功率，辨识WIL。
6. **长期可靠性**：盐沉积、清洗恢复、绝缘、腐蚀、PID、连接器和可利用率分开统计。
7. **海况状态机**：正常、降额、风暴停机、重启等待、海缆/绝缘故障。
8. **跨尺度验证**：秒级模型聚合到分钟/小时后，与调度代理比较能量和爬坡统计。

验收阈值由项目精度目标、标准要求和数据质量确定，不预设无来源数字。
