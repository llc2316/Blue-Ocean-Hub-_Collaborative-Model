# 蓝海枢纽公共基线模型 V2

## 定位

本目录是独立的第二版公共基线代码包。原工作区`v2`目录未被覆盖，可作为此前版本备份。

公共基线贯通：

```text
漂浮式风电 / 漂浮式光伏 / 潮流能设备模型
  → 统一设备适配器
  → 4.3多源聚合、联合场景与互补性指标
  → 4.4公共母线显式端口守恒
  → 4.5储能功率响应接口（本演示采用理想响应验证符号）
```

## 运行

建议使用MATLAB R2019b或更高版本。在MATLAB命令窗口执行：

```matlab
cd('C:\Users\llcqc\Desktop\多源能源\公共基线模型_v2\演示')
out = demo_public_baseline_v2(true);
```

不绘图运行：

```matlab
out = demo_public_baseline_v2(false);
```

成功时命令窗口输出：

```text
PUBLIC BASELINE V2: INTERFACE SMOKE TEST PASSED
```

## 验收范围

通过演示可以证明：

- 三个设备模型能够转换为相同4.3契约；
- 原始请求、设备接受值、实际值和预测值分离；
- 发电注入、集电损耗和辅机负荷没有重复扣除；
- 风光潮逐时聚合守恒；
- 联合场景概率满足基本约束；
- 4.4储能所需功率的符号与外部4.5响应一致；
- MATLAB可以展示功率曲线、状态机、多源聚合和母线平衡。

不能由本演示证明：

- 国产设备真实功率曲线和停机阈值；
- 储能容量足够、SOC可行或寿命经济；
- 构网控制、电压频率稳定、故障穿越或黑启动；
- 项目IRR、LCOE、制氢成本或算力收益。
