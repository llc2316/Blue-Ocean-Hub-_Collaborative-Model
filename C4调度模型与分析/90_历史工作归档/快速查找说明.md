# 历史资料快速查找说明

## 最省上下文的查找顺序

1. 先在 `历史文件索引.csv` 中按 `RelativePath` 或 `FileName` 搜文件名、章节号、版本号；
2. 再在命中的一个批次或模块内检索关键词；
3. 只有需要比较版本时，才同时读取V4前研发文件、V4末版归档和V5对应文件。

## 常用命令

按文件名查找：

```powershell
rg --files .\90_历史工作归档 | rg "4\.3|version3|功率平衡"
```

按正文关键词查找，并跳过大数据与生成缓存：

```powershell
rg -n "关键词" .\90_历史工作归档 -g "*.md" -g "*.m" -g "*.py" -g "!node_modules/**"
```

查同一文件是否内容完全一致：

```powershell
Import-Csv .\90_历史工作归档\历史文件索引.csv |
    Group-Object SHA256 |
    Where-Object Count -gt 1
```

## 大数据恢复

4.6 历史大数据默认不展开。确需复现实验时，将
`2026-07-23_V4前研发资料/03_大体量数据压缩包/4.6_large_historical_csv.zip`
解压到临时目录，并按同目录 SHA-256 清单核验；不要直接解压回V5或C5活动目录。
