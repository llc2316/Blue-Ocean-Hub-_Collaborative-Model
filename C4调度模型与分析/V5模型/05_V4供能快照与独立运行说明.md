# V5 内置 V4 供能快照与独立运行说明

## 1. 完整形态

V5 现形成以下闭环：

```text
风/光/潮资源与设备状态
  → 内置 V4 4.3 设备模型和源侧聚合
  → MP-03 可用功率、源侧辅机、集电损失
  → V5 小时级源储算用 MILP
  → 电力、氢、算力、海洋用能、弃电与 ENS
  → 独立账本残差和多目标 KPI
```

V5不再需要从历史V4末版调用任何运行文件。`foundation/`已完整复制V4的4.1—4.8
边界、接口、物理模型、高保真模型、独立评价、测试和证据文档；其中原 V4 `integration/`
也已复制，供 V2 接口验收和独立交叉复核。V4 4.9 没有复制。

源侧运行使用 `foundation/modules/4.3_source` 这一份唯一物理实现。
`source/v5_source_adapter.m` 只承担V2物理输出到V5输入的单位、时标和字段转换，
不再维护第二套4.3代码。

## 3. 两种源侧入口

### 3.1 已有源侧功率

外部 4.3、测风塔/浮标数据处理程序或企业资源平台已经给出 MP-03 功率时，直接提供：

```matlab
input.timeH = ...;
input.pSourceAvailableMW = ...;
```

此路径不会调用内置引擎。

### 3.2 设备级输入

至少提供风、光、潮中的一种：

```matlab
input.sourceCase.mode = 'device_inputs';
input.sourceCase.wind.input = windInput;
input.sourceCase.wind.parameters = windParameters;
```

光伏和潮流能字段分别为 `pv`、`tidal`，同样包含 `input` 和 `parameters`。可选字段：

- `sourceId`：设备群标识；
- `forecastAvailableW`：外部预测功率，不提供时仅用当前可用功率占位；
- `qualityFlag`：逐源数据质量；
- `parameterSetId`：参数版本；
- `hours`：所需调度长度；
- `startTimeH`：V5 时轴起点。

内置引擎输出 W、s 口径，适配器按固定等间隔、左闭右开时段取平均，转换成 V5 的 MW、
h 口径。若请求 48/72 h 而只提供 24 h 公共基线，适配器会重复基线并在审计字段中明确
`profileRepeated=true`；这只用于冻结接口验收，不属于 V5 活跃测试方案。工程资源研究
不得用重复典型日代替连续实测或再分析时序。

## 4. 计量边界

- `pSourceAvailableMW` 已扣除源侧集电损失；
- `pSourceAuxMW` 仍是独立母线需求，不能再次从可用功率中扣除；
- V5 优化器决定 `pSourceUsedMW`，并以
  `pSourceAvailableMW-pSourceUsedMW` 计算弃电；
- 供能引擎不得读取电价、氢价、SOC、算力请求或外送计划；
- V5 优化层不得修改设备功率曲线、切出/复归状态或质量标记。

## 5. 数据与公式状态

复制动作不提升 V4 参数的证据等级。公共基线中的风速、辐照、海况、潮流、装机和设备
曲线仍为 **[假设值，待企业/OEM/场址数据校准]**。设备公式和参数来源状态以快照
`docs/` 为准；没有文献或 OEM 支撑的公式继续标记 **[需查证文献支撑]**。

正式工程输入至少需要：

- 连续风速、风向、浪高、平台运动和机组 OEM 功率曲线；
- 辐照分量、组件温度、逆变器效率、污损和海况停机数据；
- 潮流流速、方向、换向、功率曲线和生物附着数据；
- 可用率、故障/检修状态、源侧辅机和集电损失实测；
- 统一时间戳、计量点、质量标记和参数版本。

来源类型应标为**政府官网、行业协会报告、上市公司公告、核心期刊论文或企业访谈一手
数据**；无法核验的数值继续标记 **[假设值，待企业调研校准]**。
