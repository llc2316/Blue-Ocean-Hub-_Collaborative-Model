# 海缆容量、登陆接纳与输电损耗内容摘要

本次补充内容对应 `sections/4_3_cable_grid.tex`，用于报告第四章数学模型中的海缆与登陆并网模块。

## 主要建模逻辑

1. 海上母线进入海缆的送端功率为 `P_send`，陆侧实际交付功率为 `P_land`，输电损耗为 `P_loss`。
2. 三者满足关系：陆侧交付功率 = 海缆送端功率 - 输电损耗。
3. 海缆送端功率受额定输电容量 `C_tx` 和海缆系统可用率 `A_tx` 限制。
4. 陆侧交付功率受登陆点逐时接纳能力 `L_grid` 限制。
5. 陆侧接纳能力由并网批复容量、陆侧电网可用率、计划检修降额和网络阻塞降额共同确定。
6. 当登陆点接纳能力不足时，无法送出的电量进入统一功率平衡中的弃电项，避免重复统计。

## 损耗模型

输电损耗采用三部分组成：

- 固定损耗：站用电、辅助设备、系统投运后的基础损耗。
- 比例损耗：换流、升压、辅助系统等近似随送电功率线性变化的损耗。
- 二次损耗：线路电阻损耗，近似与送电功率平方相关。

报告正文中给出的代理函数为：

```text
P_loss = p0_tx * y_tx + alpha_tx * P_send + beta_tx * P_send^2
```

若优化模型需要保持线性，可使用分段线性近似；求解完成后再用原二次损耗函数复算输电损耗、陆侧交付电量和电力收入。

## 建议输出指标

报告结果表中建议列出：

- 海缆额定容量，单位 MW。
- 年送端电量，单位 MWh。
- 年登陆电量，单位 MWh。
- 年输电损耗，单位 MWh。
- 平均输电效率，计算为年登陆电量 / 年送端电量。
- 海缆利用小时，计算为年送端电量 / 海缆额定容量。
- 登陆接纳不足导致的弃电量，单位 MWh。

## 数据需求

后续填入实数时，需要准备以下数据：

- 海缆及登陆站额定容量。
- 海缆、站内设备、换流或并网设备的可用率。
- 登陆点逐时接纳能力或可由容量、检修、阻塞推导出的接纳能力曲线。
- 固定损耗、比例损耗和二次损耗系数。
- 分段线性近似的功率节点。
