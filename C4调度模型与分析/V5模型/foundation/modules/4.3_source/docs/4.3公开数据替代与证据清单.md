# 4.3公开数据替代与证据清单

> 核查日期：2026-07-25。  
> 角色口径：资料检索员/优化建模师。  
> 结论边界：公开数据可减少“环境输入时序”的任意假设，但不能自动把4.3升级为工程基准。OEM曲线、项目SCADA、ADCP、保护定值、辅机和集电损耗仍需企业或项目数据。

## 1. 本轮结论

1. `somedata`中的NASA POWER UTC数据可替代合成的50 m/10 m风速、2 m气温和逐小时短波辐照输入。来源类型：**政府科研数据接口**。
2. `somedata`中的Open-Meteo Marine数据可替代合成的波高、波向和波周期输入。来源类型：**公开数据网站（非项目海测）**。
3. 当前`somedata`没有潮流流速、流向或水深剖面，不能替代潮流能输入。4.3加载器将潮流字段保留为`NaN`并将质量标志置为`false`，不会用正弦函数伪造公开数据。
4. NASA POWER的WS50M不是轮毂高度实测风速，短波字段也不是DNI/DHI分量。它们不能直接替代风机和光伏设备模型所需的全部输入。
5. GitHub中的OpenFAST、pvlib和MHKiT可用于核验模型实现、数据处理和测试方法；其参考机组或测试数据不能冒充拟选国产设备的OEM参数。

## 2. `somedata`可用数据审计

参考点为北纬21.5°、东经114.5°，覆盖2025-06-01 00:00至2025-06-07 23:00 UTC，共168小时。

| 字段 | 本地文件 | 168 h派生审计值 | 可替换内容 | 不能替代 |
|---|---|---:|---|---|
| WS50M | NASA POWER UTC CSV | 均值4.445、最小0.38、最大8.13 m/s | 合成50 m风速时序 | 轮毂高度实测/OEM功率曲线 |
| WS10M | NASA POWER UTC CSV | 168个有效小时 | 近表面风速辅助输入 | 组件高度局地风速实测 |
| T2M | NASA POWER UTC CSV | 均值27.679 °C | 合成环境温度 | 组件温度/海气边界层实测 |
| ALLSKY_SFC_SW_DWN | NASA POWER UTC CSV | 均值192.746、最大951.78 Wh/m²·h | 合成逐小时水平面短波输入 | DNI/DHI、POA和姿态响应 |
| 波高 | Open-Meteo Marine CSV | 均值1.091、最小0.46、最大1.62 m | 合成常规波高时序 | 台风极端值、平台局部响应 |
| 波向/波周期 | Open-Meteo Marine CSV | 168个有效小时 | 合成波浪状态输入 | 系泊载荷和高保真水动力 |
| 潮流流速/流向 | 无 | 缺失 | 无 | 潮流机功率曲线输入、资源评价 |

上述统计量为本地公开代理数据的直接派生结果，来源类型分别为**政府科研数据接口/公开数据网站**；不是项目场址实测，不能用于年发电量、极值或收益结论。7天样本不能代表年际、季节或台风气候。

## 3. 参数替代矩阵

| 4.3参数/信号 | 当前状态 | 本轮可否替换 | 证据和处理 |
|---|---|---|---|
| 风速、气温、短波、常规波浪时序 | 合成 | 部分替换 | 使用`somedata`公开代理；质量标记为`PUBLIC_PROXY_NOT_PROJECT_MEASUREMENT` |
| 轮毂高度风速 | 合成 | 否 | WS50M到轮毂高度的稳定度/风切变外推仍为 **[需查证文献支撑]**，需测风雷达或场址再分析校准 |
| 风机电功率曲线、切入/额定/切出 | 假设 | 否 | 需OEM/型式试验；IEA 15 MW参考机组只可做方法基准 |
| 风机平台运动修正 | 假设 | 否 | OpenFAST可生成离线高保真样本，但需平台设计和场址海况 |
| 光伏DNI/DHI/POA | 合成 | 否 | 当前只有水平面总短波；不得无证据拆分DNI/DHI |
| 光伏温度、逆变器效率、盐雾/污损/退化 | 假设 | 否 | 需组件数据表、IEC试验和项目监测 |
| 潮流流速、流向、水深剖面 | 合成 | 否 | `somedata`缺失；优先接入ADCP，其次采用Copernicus公开产品作先验 |
| 潮流机涨/落潮功率曲线 | 假设 | 否 | 需IEC/GB测试或OEM项目曲线 |
| 可用率、故障/复归状态 | 合成 | 否 | 需SCADA状态码、保护日志、检修记录 |
| 辅机与集电损耗 | 假设 | 否 | 需独立电表、机端与POI同步计量、设计潮流 |
| 风/光/潮装机比例 | 85%/10%/5%算例 | 否 | 属于容量情景 **[假设值，待企业调研校准]**，不是资源数据 |

## 4. 已新增的数据入口

`integration/load_public_reference_resource_4_3.m`完成以下工作：

- 读取NASA POWER和Open-Meteo原始CSV；
- 对齐168个UTC小时；
- 保留原始量纲和质量标志；
- 将缺失潮流显式输出为`NaN/false`；
- 不执行轮毂高度外推、DNI/DHI拆分、功率曲线拟合或电功率换算。

运行：

```matlab
addpath('integration','demos')
out = demo_public_resource_audit_4_3([],true);
```

此入口是数据审计工具，不替代`v4_source_adapter.m`的正式联调基线。工程基准应在4.2的`engineering_base`通过P0签认后，显式指定同场8760 h或多年数据。

## 7. 工程化优先级

1. 取得同场测风雷达、辐照/POA、海气温度、波浪和ADCP数据，形成至少8760 h且包含台风季的统一UTC数据集；
2. 锁定拟选风机、组件/逆变器和潮流机，导入OEM电功率曲线及状态阈值；
3. 对设备端、集电端和4.3 POI进行同步计量，辨识辅机与损耗；
4. 将公开代理数据仅作为缺测填补、先验和压力场景，不与SCADA混称“实测”；
5. 用独立年度回测MAE、RMSE、能量偏差、停复机事件和低出力持续时间后，才允许进入`engineering_base`。
