# 第5章仿真测试设计修订与复算结果 v2

## 1. 本轮角色与结论边界

本轮按“优化建模师（兼仿真分析员）”执行。结论仅对应 V5 小时级 MILP、当前参数集和确定性场景，不等同于电磁暂态、构网控制、海工生存性、全寿命经济性或概率可靠性结论。

## 2. 修订后的测试架构

1. 合成 48h：仅用于接口、状态转移、母线平衡和通道激活验证，不再用于方案排名。
2. 正常典型 48h：从年度多源场景中离线选取不含极端事件的连续 48h，用于“三大资产基准 + 22 个固定小时策略”比较。
3. 模型策略：不再作为“第23个固定方案”参与同表排名，单列评价。
4. 因果边界：每次只求解当前 1h；输入包括当前小时观测与上一小时末 BESS/H₂/设备状态，不输入之后的真实源、价、负荷或年度总供电量。
5. 固定策略优先级：先最小 ENS，再在保持最优 ENS 的可行域内最小弃能；E/H/C 约束作用于每个实际发生产品分配的小时。
6. 年度：8760 次逐小时状态连续求解，不再使用已知未来数据的非重叠 48h 分块。
7. 极端事件：设置预警—过境—恢复状态机；预警时暂停可选外送、制氢交付和柔性算力，优先恢复储备；过境期按设备可用率和源模型保护停机结果运行。

## 4. 正常典型 48h 最终结果

典型窗口：2025-01-24 00:00 至 2025-01-25 23:00 UTC；48h 全部为 NORMAL。

三类源均由 4.3 设备模型输出：风电均值 155.996MW、光伏均值 15.057MW、潮流能均值 5.005MW；峰值分别为 576.142MW、61.124MW、29.175MW。以上均为本次模型结果，不是实测值。

最终自动审计：25 个基准/固定方案全部 `auditPass=true`、`allHoursOptimal=true`、ENS=0；22 个固定策略全部 48/48 小时发生有效产品分配，最大逐小时比例偏差为 0.0200000000000007（数值误差边界内等于 2%）。

| 方案 | 弃能/MWh | 运营经济净成本/CNY | 说明 |
|---|---:|---:|---|
| 电力资产基准 | 653.944 | -2,261,838 | 负值表示运营净收益 |
| 制氢资产基准 | 2,802.108 | -1,959,593 | 未计 CAPEX |
| 算力资产基准 | 6,133.699 | -808,841 | 受柔性任务上限约束 |
| 固定策略 E60/H40 | 358.688 | -2,412,475 | 22 个固定策略中运营净收益最高 |
| 因果模型策略（单列） | 446.426 | -2,573,314 | 不作为第23个固定策略排名 |

因果模型的运营净收益比最佳固定策略 E60/H40 高 6.67%，但弃能多 87.738MWh（高 24.46%）。这表明“经济性最优”和“消纳率最优”不是同一结论，报告中应并列呈现，不能只保留有利指标。

相对电力/制氢/算力资产基准，因果模型运营净收益分别提高 13.77%、31.32%、218.15%；这些比例未包含新增资产 CAPEX、固定运维和寿命折旧，只能用于同一 48h 运营边界下的模型比较。

完整 8760h 因果逐小时运行已完成：`auditPass=true`、`allHoursOptimal=true`，三类源峰值分别为 666.4MW、78.8MW、29.175MW，未超过 680/80/40MW 容量。

全年弃能 711,316.604MWh，运营经济净成本 -299,453,207.18CNY。正常期 ENS 占绝大部分，说明“1h 经济调度 + 160MWh 短时 BESS + 禁用氢转电”的基础配置不仅台风韧性不足，对正常连续低资源时段也缺乏足够的长时备用。该结果是需要保留的容量/控制缺口，不应通过提高惩罚系数隐藏。

## 6. 极端事件增强验证

84h 事件窗口采用 30MW 氢转电、4万kg初始氢储备和 80% 初始 SOC：ENS=0、`auditPass=true`、`allHoursOptimal=true`；最低 BESS SOC 为 10.625%，最低 H₂库存约 11,243.5kg，氢转电峰值 21.894MW。

168h 连续增强烟测中，电解槽输入 2,200MWh，H₂库存由约 40,352kg 充至 72,000kg 上限，ENS=0，证明增强方案不只是单向消耗初始库存。

增强配置的完整 8760h 运行已启动，但在 2h 命令上限处被终止且未完成统一落盘，因此不得引用为增强年度结论。后续必须先实现按月/分段 checkpoint（仅保存历史状态，不提供未来数据），再续跑完整增强年度。

## 7. 尚未解决的模型边界

1. 缺少站点级 155m 风速、DNI/DHI、潮流 u/v 和浪高全年数据。
2. 算力柔性负荷仍是逐小时功率上限，没有任务积压、截止期、迁移和 SLA 违约状态。
3. 氢外运仍是等效小时流量，没有船期、泊位、储罐和航次库存。
4. 1h 因果策略避免了完美预见，但可能存在短视；应进一步比较“历史持久性预测 + 6/24h 滚动 MPC”，预测必须只由当时可获得的历史/预报生成。
5. V5 `auditPass` 仅证明小时级代数可行；秒级构网、电压频率、故障穿越、黑启动和台风结构生存性仍需独立动态/海工验证。
6. 当前运营经济结果未包含新增氢转电 CAPEX，不得直接写成项目 NPV、IRR 或投资回收期结论。
