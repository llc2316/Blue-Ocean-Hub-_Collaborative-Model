# 5.7 混合最优策略短测试与年度运营分析

年度测试迁移的是48 h自由经济优化规则，而不是53.43/15.53/31.05%的固定比例。每个窗口
重新按当期风能、价格和状态自由分配。为控制计算规模，本轮采用182个非重叠48 h分块和
最后1个24 h分块；月/窗间传递状态，BESS和储氢每窗循环。该方法是保守滚动分块近似，
不是8,760 h全局最优或24 h步长MPC。

2025年度 **[模型仿真结果]**：

| 指标 | 结果 |
|---|---:|
| 窗口 | 183，全部正退出并审计通过 |
| 年度实现E/H/C | 38.85/22.56/38.59% |
| 新能源消纳率 | 90.427% |
| 弃电量 | 163.945 GWh |
| 海缆受端电量 | 494.040 GWh |
| 氢交付 | 5,437.3 t |
| 算力服务 | 496.35 GWh-CS |
| ENS | 20.074 GWh |
| 产品与海洋服务收入 | 656.17百万元 |
| 计入运行成本 | 270.40百万元 |
| 运行净收益 | 385.77百万元 |

运行净收益不含新增CAPEX和固定运维；年度风速高度处理、价格、120 MW柔性任务池及容量
均为 **[假设值，待企业调研校准]**。下一步应改为48 h预测、24 h执行的重叠MPC，并加入
预测误差；相关随机/MPC公式为 **[需查证文献支撑]**。

复现入口为`code/run_c5_annual_48h_block_rolling.m`。默认计算8,760 h；第二个参数可在
代码验收时设为24～8,760 h的整数，例如`run_c5_annual_48h_block_rolling("",96)`，
只用于确认相对引用、状态传递和窗口审计，不替代正式年度结果。
