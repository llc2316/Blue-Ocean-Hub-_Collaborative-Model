# 在线先验—后验消纳分配策略使用指南

## 1. 策略边界

该策略不是“已知当前发电后再决定比例”，而是计划—结算两阶段：

1. 计划侧在小时`t`开始前，用截至`t-1`的风光潮实测、小时类型在线统计和当前已知事件状态估计`t`的可用功率；
2. V5在预测功率下求原始E/H/C计划份额；
3. 原始份额经过平滑、死区和小时变化限幅；
4. 结算侧读取`t`的真实物理可用功率，按稳定化计划和上一小时末物理状态求解；
5. 结算完成后才用`t`实测更新预测器。

窗口前的预测器预热只使用测试年度已经发生的历史，不改变BESS、氢库存或设备物理状态。年度测试从冷启动开始，在线形成自己的先验。

结算采用可靠性—经济性epsilon约束：先尝试同时满足`ENS=0`、计划份额和BESS储备目标；失败后依次释放计划份额与储备约束。只有无储备约束时仍达不到零ENS，才先求最小ENS，再在最小ENS容差内求经济解。方法来源类型为 **核心期刊论文**，Mavrotas (2009)。这避免“付缺供罚价同时运行可选产品”，也避免为了守储备制造当前缺供。

零ENS经济试探的单小时求解上限为0.5 s；该数值只决定何时转入完整的最小ENS二阶段，不限制二阶段最终求解时间，属于 **[假设值，待企业调研校准]**。

## 2. 估计方法与来源

- 动态后验：标准线性卡尔曼预测—更新；来源类型：**核心期刊论文**，Kalman (1960), DOI [`10.1115/1.3662552`](https://doi.org/10.1115/1.3662552)；
- 小时类型先验与动态后验融合：协方差交集，适用于未知交叉相关；来源类型：**国际会议论文**，Julier and Uhlmann (1997), DOI [`10.1109/ACC.1997.609105`](https://doi.org/10.1109/ACC.1997.609105)；
- 份额变化限幅：参考带爬坡约束的风电平滑MPC；来源类型：**核心期刊论文**，Teleke et al. (2010), DOI [`10.1016/j.renene.2009.11.030`](https://doi.org/10.1016/j.renene.2009.11.030)。

过程噪声20%、测量噪声10%、CI动态权重0.65、正常/预警/过境/恢复风险分位以及防抖参数均为 **[假设值，待企业调研校准]**。因此实现应称为“卡尔曼递推＋CI融合的工程策略”，不能宣称为已标定的最优滤波器。

## 3. 防抖规则

正常阶段默认使用：原始份额的0.35权重指数平滑、2个百分点死区、单通道10个百分点/小时变化上限；恢复阶段收紧为0.20权重和5个百分点/小时上限。处理后重新投影到E/H/C非负且和为1的有界单纯形。

正常典型48 h **[模型仿真输出]**：平均L1小时变化0.0279、最大L1变化0.1265、最大单通道小时变化0.0632，死区保持15 h，计划约束释放0 h。参数仍需用企业设备爬坡、合同容差和实际预测误差校准。

## 4. 极端事件规则

| 事件相 | 计划分位 | 运行规则 |
|---|---:|---|
| `NORMAL` | P50 | SOC目标50%；低于目标时暂停可选产品以恢复储备 |
| `WATCH` | P30 | 下修可用功率 |
| `TYPHOON_WARNING` | P10 | 暂停可选外送、制氢和柔性算力，优先恢复BESS |
| `TYPHOON_PASSAGE` | P05 | 服从场景设备停机/降额，优先刚性负荷 |
| `TYPHOON_RECOVERY` | P20 | BESS低于软目标时限制可选负荷，平滑释放 |

氢库存不设运营下限，仅保留物理非负和容量上限；不得在事件前人为增加氢或SOC。BESS正常50%、预警80%和恢复60%目标是 **[假设值，待企业调研校准]**。目标通过V5单小时末端下界和可选负荷收缩实现；若妨碍当前零ENS则自动释放，并记录`reserveConstraintRelaxationUsed`，因此是可回退约束而非模型外补能。

## 5. 运行入口

```matlab
% 正常典型48 h：三类基准 + 一个新策略
addpath(fullfile('C5','5.3对比方案与模型最优策略','code'));
run_c5_typical48_causal_comparison('',1);

% 完整年度：只运行在线先验—后验新策略，包含极端事件，不注入库存
addpath(fullfile('C5','5.7混合最优策略短测试与年度运营分析','code'));
out=fullfile('C5','5.7混合最优策略短测试与年度运营分析', ...
    'results','annual_8760h_online_strategy_extreme');
run_c5_annual_causal_hourly(out,8760,1, ...
    'model_online_prior_posterior_event_aware');
```

兼容入口`run_c5_kalman_policy_comparison('',48,1)`调用正常典型48 h；其他时长调用年度前缀测试。第三个参数是并行worker数，不再是“库存增强开关”。

## 6. 关键审计字段

- `priorAvailableMW`、`posteriorAvailableMW`、`forecastSigmaMW`、`planningAvailableMW`、`forecastErrorMW`；
- `rawPlanned*Share`与`planned*Share`；
- `planHeldByDeadband`、`planShareChangeL1`、`planFallbackUsed`；
- `reserveConstraintRelaxationUsed`、`reliabilityRelaxationUsed`、`minimumFeasibleENSMWh`；
- `bessReserveTargetSOC`、`bessReserveShortfallMWh`；
- `pComputeBaseUnservedMW`应为0，证明比较场景未把算力计入刚性ENS；
- `h2InventoryKg`用于证明库存自然形成和连续继承，不存在`h2ReserveTargetKg`字段。

只有`auditPass=true`且年度8,760 h全部落盘后，才能引用年度经济、消纳和极端事件结论。年度运行不再复算三个资产基准；基准与新策略的横向比较仅引用正常典型48 h。

当前代码口径的年度结果已生成，共8,760条逐时记录且全部求解最优。年度新能源利用率64.282%，ENS为7,128.526 MWh，关键负荷服务率96.184%，运营净收益342,110,681 CNY；台风过境24 h的关键负荷服务率仅25.963%。以上均为 **[模型仿真输出；输入含政府公开数据与假设参数]**，说明策略运行链条通过审计，但当前160 MWh BESS且无自然氢库存的配置不能满足24 h零出力韧性目标。有效结果位于`results/annual_8760h_online_strategy_extreme/`；隔离区旧结果不得引用。
