# C5 第5章方案验证与运营分析

本包是从C4/V5模型中拆分形成的第5章测试层。V5仅保留联合模型、配置、接口、
基础证据和求解内核；C5负责48 h场景、年度场景、测试数据、22方案、三类基准、
运行器、验证文档及结果管理。C5不保存V5模型副本，也不保留迁移归档树。

所有C5运行器通过相对路径`../C4调度模型与分析/V5模型`加载唯一V5内核，不依赖
当前工作目录或本机绝对路径。所有容量、价格、任务池及机制场景数值均为
**[假设值，待企业调研校准]**；仿真输出标记为 **[模型仿真结果]**。

执行顺序见`00_C5导航.md`。核心结论：48 h自由经济最优策略不是固定比例，而是
`productMix.enabled=false`下的逐时联合优化；该策略以48 h分块滚动方式运行2025年
8,760 h后，形成E/H/C约38.85%/22.56%/38.59%，消纳率90.427%。

`../C4调度模型与分析/90_历史工作归档/2026-07-31_V4与external归档/`，不参与运行。
