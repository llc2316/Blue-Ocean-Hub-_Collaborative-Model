# C5 第5章方案验证与运营分析

C5是C4/V5联合模型的测试与策略层。当前比较集合固定为：

- `baseline_E_asset_only`：仅电力外送资产；
- `baseline_H_asset_only`：仅制氢—储氢—氢输出资产；
- `baseline_C_asset_only`：仅海底算力资产；
- `model_online_prior_posterior_event_aware`：源储算用在线先验—后验协同策略。

不再使用22种固定比例方案。三类基准通过资产开关形成，不强制事后E/H/C比例；新策略也不读取48 h或年度总发电量。

合成48 h只做多源出力、状态转移、功率守恒和动态门验证。方案比较采用年度正常场景中离线选出的典型48 h；样本选择可以读取全年以判断代表性，但窗口内决策不能读取未来真实量。年度测试连续运行8,760 h并嵌入预警—过境—恢复事件，所有设备状态只从上一小时末继承，事件前不注入氢或SOC。

预测器由测试年度已发生数据在线形成小时类型先验，以标准卡尔曼更新动态后验，再用协方差交集处理两类估计的未知相关性。计划E/H/C份额经过指数平滑、死区和小时变化限幅后进入真实小时结算。比较场景中的算力全部按柔性负荷处理；氢库存只有物理非负约束，没有运营储备下限。BESS储备目标是可回退的实际约束：先释放可选产品份额，再在保障当前零ENS所需时释放储备。

当前口径的正常典型48 h四方案结果与在线策略8,760 h年度结果均已生成。年度只验证新策略的连续因果运行和极端事件响应，不复算三个资产基准；横向比较仅采用正常典型48 h。年度结果共8,760条逐时记录且全部求解最优，新能源利用率64.282%，ENS为7,128.526 MWh，关键负荷服务率96.184%，运营净收益342,110,681 CNY。以上均为 **[模型仿真输出；输入含政府公开数据与假设参数]**。有效年度证据位于`5.7混合最优策略短测试与年度运营分析/results/annual_8760h_online_strategy_extreme/`；旧年度结果已移入`_obsolete_results/`并禁止引用。

数据边界：NASA POWER小时风速、辐照度和气温属于 **[政府官网/政府科研机构公开数据]**；潮流速度、设备容量、价格、任务池、控制参数和假设台风事件属于 **[假设值，待企业调研校准]**；仿真表属于 **[模型仿真输出]**，不能替代企业实测或投资收益结论。
